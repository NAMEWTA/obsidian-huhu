# bz 借鉴功能

**归物本**：基于档案物品类型预设的物品生命周期视图，物品记录仍是档案实体。
_Avoid_: 物品库、belongings 库

**书页日记**：以书页形式阅读与书写周期日记的工作台页面，正文仍是一日一篇的周期笔记。
_Avoid_: 日记本数据库、回忆墙

**人物阅读层**：档案中人物类型实体的阅读与手工纪事视图，不另建联系人主库。
_Avoid_: 脸谱库、联系人系统

**数据体检**：由各数据 owner 贡献检查项的只读扫描与有限修复功能。
_Avoid_: 自动修复、全库清理

**通知渠道**：通知基础设施中可注册的投递方式，如站内与系统通知。
_Avoid_: notify
