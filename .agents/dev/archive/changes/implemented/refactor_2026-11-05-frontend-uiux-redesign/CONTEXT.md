# HUHU 前端设计系统

**工作台**：HUHU 在 Obsidian 内的单一主视图，由图标轨、二级栏、主区和按需右详情组成。
_Avoid_: 应用壳、网页

**图标轨**：工作台最左侧 52px 的模块切换栏，底部固定通知与设置。
_Avoid_: 侧边栏（与二级栏混淆）

**二级栏**：按当前模块提供的导航面板（目录树、分组、筛选），可拖动调宽，没有内容的模块不显示。
_Avoid_: 左侧详情

**右详情**：主区右侧的非模态详情区（Inspector），宽度不够时改为覆盖 Sheet。
_Avoid_: 侧边栏、抽屉页

**HUHU 主题**：HUHU 自有的语义 token 与浅色“纸”/深色“墨”两套主题，默认生效。
_Avoid_: 预设皮肤

**跟随 Obsidian**：外观设置中的可选模式，开启后语义 token 映射为宿主主题变量。
_Avoid_: 兼容模式

**强调色**：主操作、选中与焦点共用的唯一品牌色，可在设置中从固定色组中选择。
_Avoid_: 主题色（与整套主题混淆）

**密度**：内容层的紧凑/舒适两档，只改变行高、段落与内边距，不改变字阶和触控命中区。
_Avoid_: 缩放

**差异视图**：版本页里所有“两个版本之间改了什么”的阅读界面，统一由 `@pierre/diffs` 渲染，包括更改、提交详情、A⇄B 比较、笔记历史与独立比较叶子。
_Avoid_: diff 编辑器（它不是正文编辑器）

**比较端点 A / B**：一次比较的旧端（A）和新端（B），可以是提交、引用、index、工作树、本地历史快照或当前编辑器快照。
_Avoid_: 左边 / 右边（堆叠布局里不存在左右）

**改动块**：一段连续的新增/删除及其上下文，可单独暂存、取消暂存或还原。
_Avoid_: chunk、hunk（界面文案）
