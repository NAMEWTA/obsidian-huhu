# UI-001 设计评审（结论报告）

结论：**通过，待用户集中确认**。评审对象为本包 `final/index.html` 及候选入口，演示数据。

## 方法
在 headless Chrome 中实际打开终版，在 1440px 与 390px 下逐页逐状态截图（12 页、81 个状态），并做缩略图总览比对；单独检查深色“墨”、跟随 Obsidian、日期弹层、对话框和窄屏 Sheet。

## 观察
- 产品适配：四区骨架和宿主 chrome 分得清楚；主区只有一个主按钮；状态同时用图标、文字和颜色表达。
- 层级：衬线只用在阅读与问候，界面统一用无衬线；页头 16/600、元信息 12，与正文 14 层级分明。
- 色彩：纸/墨两套主题在所有模块一致；强调色只出现在主操作、选中、焦点、今天和进度上。
- 一致性：列表行、选中条、分段控件、开关、右详情页头与底栏在任务、自动化、通知、保险箱中形态相同。

## 发现与修复（已复核）
1. 日期弹层在编辑对话框中被遮挡（层级 55 低于对话框 60）。已把 popover 层级调为 65（低于 toast 70），复核截图中弹层位于对话框之上。
2. 设置页夹具在“深色/跟随 Obsidian”之后串到后续状态。已改为每个设置状态显式设定明暗与来源，复核通过。
3. 任务日历最后一行露出网格底色。已补齐尾部空格，复核通过。
4. 加载态只显示骨架、缺少文字。已加 `role=status` 的“正在读取…”提示。

## 未验证
真实 Obsidian 主题下的“跟随 Obsidian”实际观感、真实触屏、多窗口。原型使用 Air Datepicker 承载视觉规格，生产使用 DayPicker v10，需要在实现时重新截图对照。
