# HUHU UI / UX 重构交付包 · v1.2

日期：2026-11-05（Asia/Taipei）。

## 先看原型

直接打开 `prototype/HUHU_Workbench_Prototype.html`。它内嵌 HTML、CSS、JavaScript、SVG 图标和日期组件，不需要安装依赖或访问 CDN。

重点体验这次调整：

1. 任务 → 日期筛选，或打开任务编辑器：中文日期选择器、年月切换、今天、清空，颜色跟随外观主题。
2. 自动化 → 点击一条自动化：列表保持在原位置，右侧打开详情；滑动开关直接切换启用状态。
3. 档案 → 左侧目录：展开类型查看具体档案，点条目切换；展开与选中分开操作。
4. 任务 → 全部 / 已完成：已完成任务标题和说明显示清晰划线，重新打开恢复普通样式。
5. 设置 → 外观：更换主题、强调色、密度与字号，核对公共组件的统一表现。

`Ctrl / Cmd + K` 打开命令面板，`Esc` 关闭当前浮层。保险箱演示密码为 `huhu-demo`，不要输入真实账号凭据。

## 再看重构计划

- `plan/Frontend_Refactor_Plan.md`：当前工程基线、目标架构、公共组件、布局与 token、全模块改造范围、任务依赖、旧代码删除项及验收标准。
- `plan/Reuse_Research.md`：现有组件与外部开源方案的复用调查、许可、适用范围及原始来源。

生产计划以当前 HUHU `main` 的固定提交 `37fcede4210a19bcc2a74809e7fdd301e5717957` 为依据。GitHub 已无法读取原 `dev` 分支，因此旧原型参考的 dev 提交仅作为历史记录。

本计划按用户要求直接替换旧实现，不设置双轨 UI、旧接口适配层、旧 CSS 兼容层或旧数据迁移承诺。具体数据初始化和切换范围以计划正文为准。

## 源码与验证

- `source/`：本次原型的完整构建源码，包含内嵌日期库及许可证。在该目录运行 `node build.mjs`，产物写入 `dist/`。
- `qa/`：本轮检查记录、针对性回归和实际浏览器截图。
- `MANIFEST.json`：包内文件大小与 SHA-256，用于核对交付文件。

原型源码是独立 HTML 的演示工程，不是修改完成的 Obsidian 插件。生产重构继续使用 HUHU 已有 React / TypeScript、Radix、共享 Tree 和 Obsidian 宿主服务。独立原型内嵌 Air Datepicker；生产计划使用 React DayPicker 和现有 Popover。二者通过相同交互要求对照，不在生产中增加兼容桥。

普通界面操作使用浏览器本地数据。终端、智能体输出、自动化执行、Git、系统通知和保险箱加密仍为标明的模拟，不会操作真实 Vault 或系统进程。当前 main 新增能力的生产覆盖以重构计划为准，不将独立原型的历史功能地图表述为对当前 main 每项功能的完整实现。
