# HUHU · Oil UI 交互原型 v1.2

这是一份独立运行的个人工作台设计原型。功能地图延续已交付的 HUHU dev 历史基线，本轮按用户反馈统一日期、自动化详情、档案目录和任务完成态；配套生产重构计划以当前 main 的实际技术栈为依据。

## 使用

直接用现代桌面浏览器打开 `dist/HUHU_Workbench_Prototype.html`。文件中已经包含全部 HTML、CSS、JavaScript 和 SVG 图标，不需要安装依赖或连接 CDN。

- 左侧图标轨切换功能；需要目录的功能提供二级导航。
- 顶部“笔记”进入宿主笔记场景，包含导航器、阅读、批注和历史入口。
- `Ctrl / Cmd + K` 打开命令面板，`Esc` 关闭浮层。
- 设置 → 外观：主题、浅深模式、强调色、密度、字体、阅读与编辑器样式。
- 页面操作 → 尺寸预览：在 390 / 820 px 的独立视口中操作。
- 顶部下载按钮重新导出完整 HTML；页面操作可导出当前演示数据。
- 保险箱默认演示密码为 `huhu-demo`。仅使用虚构示例，解锁内容保留在内存。

## v1.2：四项交互修订与完整交付

本轮更新日期为 **2026-11-05**。

- **统一日期组件：**离线内嵌官方 Air Datepicker 3.6.0，所有日期与日期时间字段使用相同的主题、字体、间距、焦点和错误提示；支持文本输入、日期选择、今天/清除、范围约束和键盘关闭。
- **自动化右侧详情：**点击列表项打开右侧详情，保留搜索、筛选与滚动位置；详情中的编辑和运行记录仍保留当前列表上下文。启停用滑动 Switch，点击开关不会打开详情。
- **档案目录树：**类型目录下展示档案记录与已保存视图，支持独立展开、折叠、搜索路径、数量和键盘导航；管理入口保留在树下方。
- **明确完成反馈：**主任务列表、日历与看板中的已完成文本使用删除线，配合勾选与状态提示；重新打开立即恢复正常文字，日期和关联资料保持可读。

生产重构方案见 [完整计划](docs/Frontend_Refactor_Plan.md) 和 [组件复用调研](docs/Reuse_Research.md)。当前仓库已具备 React 19、Radix、Headless Tree、TanStack Virtual 和 Tailwind 4。正式实施复用现有 Switch/Tree，日期采用 `@daypicker/react` 与现有 Popover；原型的 Air Datepicker 不进入正式插件，也不增加两者间的兼容层。

当前生产基线为 `main@37fcede4210a19bcc2a74809e7fdd301e5717957`（0.0.3）；本次查询 dev 分支不存在。完整计划覆盖当前 main 的新模块，**不能把旧原型的功能地图理解为对所有新生产能力的实现声明**。

本轮实际测试、截图和验证边界见 [v1.2 验收记录](qa/v12-verification.md)。以下 v1.1 内容保留为历史记录。

## v1.1 审查结果

本轮审查日期为 **2026-11-05**。保留已认可的布局与视觉，重点修正数据保存、表单草稿、对象引用、异步状态和恢复流程中的真实缺陷。

- **保存与多窗口：**按基线、本页和另一窗口的数据进行三路合并，保留模块持有的对象引用；冲突不会静默覆盖。最终合并结果通过完整结构与引用校验后才写入。同步保存失败会原位恢复提交前状态，重试不会重复新增；异步或部分保存提供重复提交保护和明确提示。
- **表单与设置：**未保存输入在取消、Esc 和遮罩关闭时受到保护；内部选择器与确认框取消后恢复父表单。外观设置统一规范化颜色、数值及枚举，支持合法的部分配置；组件样板的全部字段可以保存并在刷新后恢复。
- **任务、档案、自动化：**修正重复任务更新边界、日期规则、分页、草稿持久化、旧修订解释、升级与回滚冲突，以及自动化的重复通知、停止竞争、刷新中断和投递重试。
- **智能体、版本与保险箱：**修正运行与等待的过期回调、会话归属、同文件版本比较、正文恢复与撤销、模拟 Clone 取消，以及锁定后的明文和异步结果清理。
- **首页与笔记：**修正笔记草稿、移动与重命名引用、删除和撤销、高亮锚点、组件撤销、运行日期、CSV 与媒体导入、规则匹配及计时器状态。

本轮 **156 项独立 Node 检查全部通过**，覆盖状态、数据和公共接口；这些结果不等同于完整浏览器端到端验收。浏览器另行验证了未保存表单保护、自动化嵌套弹窗返回、设置刷新持久化、菜单键盘焦点、390 / 820 px 预览入口、390 px 预览无页面级溢出、覆盖式抽屉与外观配置。分项数量、操作证据与历史基线见 [检查记录](qa/verification.md)。

本轮画面：[深色首页](qa/reviewed-home-dark.jpg) · [浅色档案、侧栏与详情](qa/reviewed-archives-light.jpg)。

**交付验证边界：**浏览器文件上传被安全审批拒绝，本轮没有上传文件、没有覆盖数据；文件选择器导入流程仍未获得浏览器验证，导入验证器的 50 项代码检查已通过。页面“再次下载”回退链接可见，但自动下载事件未被浏览器工具成功捕获；完整 HTML 已直接生成，可从交付文件取得。

## 功能边界

普通界面操作使用浏览器本地状态：新增与编辑、筛选排序、看板编排、关联选择、草稿、历史、通知已读、主题及设置。数据保存在当前浏览器；浏览器策略不允许保存时会显示持久错误提示，并提供导出路径。不同浏览器、不同 URL / 本地文件位置不保证共享同一份数据。

终端、智能体输出、自动化执行、Git、系统通知、账号额度与保险箱加密属于**明确标识的交互模拟**。这些路径展示输入、等待、结果、错误与恢复的体验，不会调用真实系统进程、网络服务或修改原 HUHU 仓库。原型不能存储真实密码或 API 凭据。

档案二进制附件在当前会话保留原文件用于下载；刷新后只保留元数据，需要重新选择原文件。页面会明确显示不可用状态。

English 选项切换公共导航、常见操作和状态文案；业务示例及部分帮助说明保留中文。离线字体使用设备已安装的字体和 CJK 回退；未内嵌生产工程的字体包。

## 源码与构建

源码按职责拆分，构建结果始终是一个完整 HTML：

- `core.js`：壳层、路由、表单/抽屉/对话框、保存事务、公共控件。
- `data-safety.js`：三路合并、默认结构补齐和保留对象引用的原位同步。
- `import-validation.js`：全量数据的模块结构、身份、嵌套字段与引用校验。
- `modules-a.js`：任务、档案、自动化。
- `modules-b.js`：智能体、版本管理、保险箱、通知。
- `modules-c.js`：首页看板、笔记导航/批注、图标、内容浏览。
- `settings.js` / `theme-adapter.js`：设置与主题。
- `styles.css`：统一样式；`modules-a-refinements.css` / `interaction-refinements.css`：本轮树、开关、详情和完成反馈。
- `date-picker.js` / `date-picker.css`：成熟日期库的统一字段适配与主题；`vendor/air-datepicker/`：官方分发与许可证。
- `icons.js`：内嵌 SVG 图标。
- `preview-tools.js`：原型尺寸检查；`boot.js`：初始化。

运行 `node build.mjs` 生成 `dist/index.html` 与下载版本。构建会检查全部脚本语法。无需安装 npm 依赖。`--partial` 仅用于开发中检查共享外壳，不是交付构建。

当前完整构建的文件大小、摘要、内联资源和源基线记录在 `qa/build-manifest.json`。README、计划和验收记录不计入内联 HTML。

本原型为设计评审和下一轮生产重构提供具体依据，生产接入应继续复用现有 React / TypeScript、公共组件及 Obsidian 适配层。

## 此前交付基线的设计评审反馈

- 计划日期与截止日期是两种事件；日历明确标注，日期相同合并展示，未设置处理日明确提示。
- 首页待办标题、数量和筛选集合一致，不把全部未来待办称为“今天与更早”。
- 首页突出任务入口；桌面移动/缩放把手在悬停或键盘聚焦时出现。
- 详情抽屉对应的档案行显示选中态；短字段和邮箱等采用一致的单行溢出策略。
- 创建恢复副本与替换当前正文使用不同确认说明；副本不覆盖原笔记。
- 有目录层级的模块使用完整三栏；历史 dev 基线采用无二级目录的首页、任务、自动化和保险箱保留较宽工作区，用户仍可切换全局功能。

实际检查记录见 `qa/verification.md`。功能地图描述已实现的原型路径，不意味着全部状态已逐个在真实浏览器中穷举。
