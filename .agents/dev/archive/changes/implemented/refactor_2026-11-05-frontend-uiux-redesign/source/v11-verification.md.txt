### 本轮关键修复

#### 保存、导入与公共界面

- 三路合并同时考虑保存基线、本页数据和另一窗口数据，独立字段及记录能够合并，同一内容冲突不会静默覆盖；原位同步保留模块持有的集合与记录引用。
- 每次写入前校验最终合并结果的完整结构及引用，避免两个分别可用的状态合并后生成孤立引用。
- 同步提交保存失败，在进入首个异步等待前原位恢复提交前状态并保留表单输入；同一真实新建任务回调连续两次配额失败后仍为 7 项，恢复存储后再提交恰为 8 项。
- 异步或已经部分保存的提交具有重复执行保护；失败不会继续给出同次成功提示。相关回归覆盖共享提交处理器，未冒充浏览器存储故障测试。
- 多窗口监听根据明确编辑状态及表单指纹决定是否推迟同步；常驻导航 guard 的存在不再让空闲窗口永久被当作正在编辑。
- 用户关闭、Esc 与遮罩走统一未保存保护；`isDirty` 支持跨重绘的草稿判断，`onDismiss` / `onCancel` 恢复内部选择器与确认框的父编辑器。内部强制关闭与用户放弃各有明确回调边界。
- 全量导入先检查结构、再原子替换；失败保留原数据。外观 token 统一规范化，非法值拒绝，合法部分配置补齐；设置表单与抽屉的输入及焦点行为补充保护。

#### A：任务、档案与自动化

- 修正“本次及以后”使用错误日期边界、隐藏重复结束值、系列身份、日期和 Cron 校验、筛选与最后一页偏移。
- 档案和关系草稿及时保留；模板不会串类型；旧记录按自身 schema 修订解释，明确升级后才采用新定义。
- 定义发布正确删除被移除的属性；JSON、普通发布及合并共用结构检查。升级、恢复和回滚拒绝覆盖后续修改，历史快照与既有记录保持原身份。
- 二进制资料在当前会话下载原文件；刷新后只有元数据时明确说明不可用，避免生成空文件。
- 自动化通知遵守渠道并去重，停止后的旧回调不再完成任务；刷新标记本地运行中断，原任务投递重试幂等。时间预览按实际时间及时区处理规则边界。
- 自动化重绘保留脏状态，文件、命令与笔记选择器关闭后返回原稿；档案设置取消目录预览后恢复两个原始输入。

#### B：智能体、版本、保险箱与通知

- 运行、停止、恢复、归档与终端等待绑定具体会话和执行身份；迟到回调、超时与取消不会污染新运行。
- 历史筛选和导入核实 Space 归属，配置导入验证嵌套结构与现有引用。
- Diff 按同一路径和真实版本构造比较；正文恢复、副本与撤销复查目标身份、当前正文和回执，避免覆盖后来的编辑。
- 模拟 Clone 取消后旧结果不会接管新弹窗；保险箱锁定或离开清理明文与草稿，迟到的文件/剪贴板回调不能重新显示锁定内容。
- 通知跳转验证目标是否仍可用，失效目标不提前标记已读。

#### C：首页、笔记、批注与内容

- 笔记正文、独立草稿、复选任务与快速捕捉共同保留未保存内容；关闭最后一个标签不会自动重新打开。
- 重命名、移动及文件夹变更同步更新链接、草稿、图标和快捷入口；批量目标冲突先拒绝，删除与撤销保留后续新增和修改。
- 高亮按锚点区分重复文字，正文前缀改变后调整位置，目标消失时标记脱离；恢复与撤销同时保留正文、草稿和锚点状态。
- 组件移除撤销保留后续变更，跨看板拖放及非法尺寸受到约束；日期筛选、习惯连续天数和日历投影使用运行日期。
- CSV 引号与日期校验、媒体读取失败和取消、图标规则匹配及设置跨页草稿得到修正；阅读计时与番茄完成去重。
