# 术语入口

定义只维护在所属主题文件，不在此复制正文。下列是已采纳领域合同，具体落地与验证范围见来源。

- Space／空间、Session／会话记录、终端运行、被动通知、状态等待、明确寻址：[终端协作与身份](context/2026-10-31-agent-workbench-refactor.md)。cwd 不是身份，输入回执不是任务成功。
- 高亮、摘录卡片、行级批注、脱离：[高亮摘录](context/2026-10-31-highlight-first.md)。实体升级的未闭合需求仍在 changes，不因知识迁移宣称完成。
- 档案类型、字段、实体、关系、定义修订、迁移权威切换、原生草稿冲突、归物本、人物阅读层：[档案与历史](context/2026-10-31-unified-browser-versioning-archives.md)。迁移术语只适用于仍受支持的自定义 schema 升级。
- 预发布旧数据、兼容层、网页快捷卡、启动关键路径、显示名称、稳定身份、Hook 发布序号、书页日记、数据体检、通知渠道：[产品线与基础能力](context/2026-11-04-dev-stabilization-overhaul.md)。

Bot 的 Run／Effect／Receipt 等旧领域对象已退役，不并入现役术语，见[历史释义](../archive/notes/context/2026-10-31-huhu-bot-architecture.md)。
