# 现役笔记的维护

这些记录描述当前交付决定。写法见[知识目录与笔记格式](notes-guide.md)，文字要求见[项目文字规范](writing-guide.md)。

## 与实际交付保持一致

代码修改路径、符号、默认值或机制时，同一变更中同步修改相关笔记。直接改正过时事实，不追加变化流水。只核验当前范围，不给未检查内容刷新日期。

笔记不再可能指导未来工作时，按[保留与替代](retention.md)判断归档或删除，不继续无限维护。

## 事实刷新与决策反转

实现事实原地更新；决策或其理由反转时创建后继记录并交叉链接。完全被替代的旧笔记，只有在独有理由、方案、后果、否定保证、验证和覆盖缺口已完整承接后才可合并删除。
