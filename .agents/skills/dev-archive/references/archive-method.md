# 按未来价值归档项目笔记

缩小活动决策资料集，同时保留仍能指导工作的历史。按语义判断每篇笔记；字数和年代仅用于发现候选项，绝不作为归档标准。

## 阅读约定

分类前阅读 [知识目录与笔记格式](notes-guide.md)、[历史笔记规则](historical-notes.md)以及[现役笔记规则](active-notes.md)。使用当前代码、配置、包文档、生成的目录、较新的 项目笔记 和入站链接，判断某段理由是否仍然负责或约束任何事物。

## 新增笔记时检查替代关系

起草前应用[创建标准](notes-guide.md#何时新增或更新)。每篇新 项目笔记 都会触发一次范围明确的活动笔记审计，覆盖同一决策、机制或被拒绝方案。撰写新笔记时，对每项完全替代或部分替代进行分类：符合条件的已实施记录在同一次变更中归档；部分替代或仍有独立价值的理由保留并交叉链接；拒绝过时提案；删除不再能阻止合理误判的已拒绝笔记。新责任记录吸收了全部独特论点时，应用 项目笔记 合并规则；不要把已知的对应关系拖到以后的全资料审计。

## 按未来价值分类

按生命周期采用以下结果：

- **已实施——删除：** 删除仅描述小型界面调整或纯机械性变更的完整记录，并修复或移除入站链接。局部缺陷修复、性能变更、新能力，以及实质性的行为或责任归属决策，不能仅因为已经实施就归入此类。先应用这一标准，再判断保留或归档。
- **已实施——保持活动：** 如果理由、备选方案、否定保证、持久化或传输语义、责任边界、安全规则或重新引入条件可能指导未来修改，就保留。分类对象是决策，不是实现动作：机械性重命名或类型提取，也可能记录长期有效的命名、兼容性或责任规则。篇幅无关。
- **已实施——归档：** 实质性的历史决策已经完成，不太可能指导未来工作，但其历史理由仍值得保留时归档。满足直接删除标准的记录不归档。
- **提议中——永不归档：** 有效提案保持活动；如果不再值得推进，给出真实拒绝理由，并满足已拒绝生命周期的格式。
- **已拒绝——仅作为防误用提醒保留：** 只有落选提案仍是有诱惑力、有意义的错误选择，且笔记说明其落选原因时才保留。
- **已拒绝——删除：** 被拒绝想法已过时、已被替代、不再合理，或不太可能防止重复争论时，删除整个记录。修复或删除入站链接。

不要为达到配额而归档。检查范围内的每篇笔记，用同一原则分类相似组，对接近边界的情况运用判断，并在交接中记录真正难以取舍的决定。

## 校准示例

下列示例确定判断尺度；字数用来说明篇幅不是判断标准。

删除以下已实施笔记：

- 折叠侧栏控制轨——533 词：已结束的轻微界面行为。
- 议题策略模块归属——已经完成的函数搬迁与导入重接，行为没有变化。

保留以下已实施笔记：

- 事件溯源会话——248 词：基础事实来源与持久化边界。
- 单一应用主目录解析器——596 词：跨产品责任归属规则。
- 项目会话目录——628 词：持久存储与身份策略。
- 并行推送前检查——400 词：接近边界，但仍指导检查调度和资源调整。
- 移除的图片内容块——334 词：在多模态支持落地前保留，因为它说明协调重新引入的条件。

对于已拒绝笔记：

- 保留合并上下文压缩包拆分的提案——426 词：合并这些包的诱惑仍然存在。
- 删除通过工具调用流式传送工作流进度的提案——972 词：其 ACP/UI 前提已过时。
- 删除丢弃 ACP 终端元数据的提案——362 词：后来仅面向自动化的 ACP 决策已解决此问题。

## 归档一个已实施记录

1. 确认它已完整交付、没有继续约束当前实现的部分，并有独立历史价值。保留当前负责记录、替代范围及核对证据。
2. 将记录从现役知识目录移到 `.agents/dev/archive/notes/`，保留原分类与文件名。无同名冲突时才移动；有配套的本地示例或附件时一并保留完整关系。
3. 正文保持历史语义，只增加归档日期、当时适用版本和当前替代位置。不把格式整理、翻译、事实刷新或出站链接修复夹入普通归档。
4. 搜索活动正文的入站链接。优先指向当前负责记录；有意引用历史时才改为归档位置，否则删除。移动需求目录时也检查其相对代码与部署链接。
5. 回读文件和链接，使用 Git 差异确认本次范围。维护历史无需双语记录、哈希封印或额外状态引擎。

归档记录是历史快照，不是当前行为依据。后续有明确删密或事实纠错需要时，记录修订事实，不悄悄覆盖历史。

## 验证与报告

检查本次移动、删除和导航的相对链接，以及现役代码引用；运行项目已有的相关文档检查和 `git diff --check`。没有行为修改时不为归档构造测试，不重复无关全套验证。

报告：保留的活动已实施笔记、删除或归档的已实施笔记、保留或删除的已拒绝笔记、被拒绝的提议中笔记（如有），以及每个真正难以取舍的案例及其字数和最终结果。不要声称归档笔记的出站链接有效：本次检查未覆盖它们。
