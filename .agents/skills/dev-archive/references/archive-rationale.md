# 当前知识与历史记录分开维护

## 问题

已实施 项目笔记 作为当前决策记录持续维护，所以活动资料集中的每个路径、符号、默认值、译文、代码围栏、包引用和出站链接都带来维护义务。理由仍能指导未来工作时，这个成本合理；对于已经结束的界面细节、小修复、被替代的实现动作，或当前权威记录已在别处的流程历史，这个成本不合理。删除所有低价值已实施记录会抹去有用的历史证据，而保留每个已拒绝提案会保存既不再合理、也没有教育意义的想法。资料集需要一条保留边界，区分活动指导与冻结历史，并且不把归档变成另一层维护负担。

## 决策

只描述小型界面调整或纯机械性变更的已实施笔记，连同完整记录一起删除，并修复或移除入站链接。小型实现仍可能承载长期的命名、兼容性、责任或行为决策；这些记录仍有资格保留。只有其他已实施 项目笔记 可以归档：交付决策已完成，其理由不太可能指导未来工作，同时仍有历史决策价值。基础边界、持久化与传输语义、安全规则、反复出现的设计诱惑，以及尚未解除的重新引入条件，无论年代或字数都保持活动。提议中笔记不进入归档；过时提案变为已拒绝。已拒绝笔记只在能阻止有诱惑力、有意义的错误选择时保留，否则删除完整记录。

归档路径为 `.agents/dev/archive/notes/`，保留原主题分类与文件名。归档时移动完整记录与必要附件，保留正文，增加归档日期、当时适用版本和当前替代位置，并修复活动文件的入站链接。判断关注事实与完整性，不把标题标点、空行布局或排版偏好当作归档前提；强制修复这些内容会改写历史。

日常读取先指定当前代码与 `.agents/dev/notes/`，不把归档混入默认上下文；项目搜索工具可按已有约定排除历史目录。历史查询显式指定归档目录，因此仍能主动访问历史，同时不把冻结事实混入活动决策搜索。

归档后，记录永久冻结，作为历史背景而非当前权威依据。不为包重命名、行为变化、翻译标准、格式规则、失效出站链接或后来的文档约定更新它。活动正文可以有意链接到归档笔记、将链接重定向到当前权威记录，或删除链接。因此仓库检查验证指向归档文件的链接，但不把归档文件作为链接来源。

维护边界由目录、明确的历史标记、Git 和实际链接检查承担。当前文档检查不应为了新标准逼迫重写历史。普通归档不建立封闭类别、双语配对、哈希封印、固定清单或专用状态网关。必要的历史修订必须说明原因与范围，保留修订事实。

[归档方法](archive-method.md)负责分类：逐篇语义审计，以当前代码和文档确认现在由谁负责，只把字数用于初筛，使用保留、归档、删除示例校准，并报告真正难以取舍的结果。

替代关系在新 项目笔记 撰写时检查，不延后到将来的资料清理。作者比较新笔记与覆盖同一决策、机制或被拒绝方案的活动笔记，并分类每个完全替代或部分替代。符合条件的已实施记录在同一次变更中归档；部分替代和有独立价值的理由保持活动并交叉链接；提议中与已拒绝的匹配项遵循各自生命周期规则。

## 考虑过的替代方案

**删除所有离开活动资料集的笔记。** 拒绝，因为已实施记录即使对未来指导有限，也可能提供关于已结束决策的有用历史证据。明确标注的历史归档能保留这些证据，同时不假装它们仍然有效。

**让所有已实施和已拒绝笔记保持活动。** 拒绝，因为不再帮助未来决策的记录会增加维护工作与搜索噪声。已拒绝笔记尤其只有能阻止合理误判时才值得保留。

**让归档笔记继续出现在默认仓库搜索中。** 拒绝，因为归档事实按设计可能过时，却可能因词面匹配排在当前结果前面。历史工作可以显式搜索归档目录。

**把替代关系清理推迟到周期性的全资料审计。** 拒绝，因为替代笔记的作者掌握最新的归属与重叠证据。推迟会留下冗余的活动权威记录，并让后续分类更昂贵。

**也归档已拒绝或提议中笔记。** 拒绝，因为归档表示“已实施的历史决策”。过时提案需要明确拒绝；没有防误用价值的拒绝记录应删除，不应进入第二个低价值存放区。

**继续对归档笔记应用全部文档检查。** 拒绝，因为后来的格式、翻译、代码、包或链接规则会迫使重写历史快照。通过版本记录和有范围的复核保留历史完整性。

**只冻结理由，允许刷新事实。** 拒绝，因为这会重新引入活动资料集的判断与翻译负担，并让哪些句子属于历史变得不清楚。当前事实应放在活动文档或新的活动 项目笔记 中。

## 后果

活动资料集成为预计会影响未来工作的决策集合；未来指导价值较低、但具有实质历史意义的决策，仍可显式搜索与链接，同时不消耗维护注意力，也不出现在父目录搜索中。撰写新笔记包含范围明确的替代关系检查，避免替代决策悄悄留下冗余活动记录。拒绝记录不再保护有意义的选择时可以删除；提议中工作不能通过归档悄悄逃避结论。归档只增加明确的历史位置、一次性归档说明和必要链接维护。归档事实与出站链接按设计可能过时，因此读者与 Agent 必须将活动代码和文档视为权威，并只把归档笔记作为历史引用。
