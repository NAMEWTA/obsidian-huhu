# 历史笔记的使用

历史笔记位于 `.agents/dev/archive/notes/`，保留必要主题分类与文件名。它们是当时决策的快照，不是当前权威依据。新事实放在活动文档或新的现役笔记。

归档时保留正文，增加归档日期、当时版本与当前替代位置，移动前检查目标冲突，移动后修复活动资料的入站链接。不要为现行代码路径、排版习惯或新的写作规则改写历史。

默认搜索不混入历史目录；确有追溯需求时明确搜索该目录。当前文档只在说明过去时引用历史。历史出站链接可能过时，不将其全部纳入日常修复义务，也不声称未经检查的链接有效。

使用 Git 保存变更事实，不建立强制双语三文件组、封印哈希或追加清单。删密、事实纠错或用户明确要求的修订另行记录，说明改了什么和为什么；不伪装成原始快照从未变化。
