# 人工参与的最小复现

优先使用智能体可直接驱动的真实路径。只有目标设备、认证或操作无法由可用工具完成时，才使用 [交互复现脚本](../scripts/manual-reproduction.mjs)。先读脚本并替换其中目标命令和症状判断，不要把模板本身当作已验证的复现。

脚本调用方式：`node <本技能实际路径>/scripts/manual-reproduction.mjs`。保持凭据在环境变量或已授权密钥位置，展示输出先脱敏。向用户说明需要完成的唯一动作、完成标志和无法自动操作的具体原因；读取日志后继续诊断，不把整个调查交回用户。

模板收集与判断现有故障，可以为测试先行或其他修复方法提供反馈。存在合适自动化接口时，把真实复现保留为回归测试；实现修复后，仍使用相同原始路径确认结果。清理临时观测与测试数据，保留必要证据。
