# 主机总入口

此文件记录已核实事实，不包含真实密码。实际使用时填入验证结果，不把占位符当成交付。

## 主机身份、登录账号、项目根与核对时间

记录主机标识、实际身份、登录账号、真实部署根和最近核对时间。区分已登记、目录存在、两侧文档已核对、项目运行环境已就绪。新位置按用户指定或已授权实际目录确定，不从当前工作目录或上次主机推断；换登录账号不自动更换已有部署根。

## 服务一览

记录主机、应用或共享服务、访问入口、账号用途、当前版本、最近验证时间、持久化和配置路径。服务端普通文档不写密码。登记本次实际发现的入口，未核对项明确标记，不声称已部署。

## 公网与内网访问

已有公网入口时记录映射、网络条件、开放新服务的真实操作入口和禁止暴露的端口。入口流量与出口代理是不同连接，分别核对。

## 服务说明

记录主机级服务的监听端口、隧道地址、配置路径、适用规范，以及应用备份恢复摘要。项目完整启停命令引用项目运行手册，不把所有项目全文合入主机总册。

## 资料索引

使用本项目实际维护的部署规范、服务清单、入口映射与发布历史相对路径。保持 Markdown 索引即可，不要求 JSON 登记表、严格状态流或执行网关。
