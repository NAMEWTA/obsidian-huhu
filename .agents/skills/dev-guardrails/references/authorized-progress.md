# 不让工作等待人类

适用：当你想针对可逆工作询问‘我应该做 X 吗？’时使用。

人类以异步方式监督。代理必须保持能够推进。作出合理决定，继续执行，让人类事后纠正方向。代码改动可逆、可审查，因此一次错误决定的代价通常小于阻塞工作的代价。

- 先执行，再展示。完成工作，展示结果。不要问“我应该做 X 吗？”在现有授权和任务范围内直接做 X，并解释原因。
- 让系统能够自我修复。注意到问题时记录下来，在下一轮修复。
- 高影响动作如共享分支强推、生产数据删除，先核对具体目标与现有授权；已有明确授权不重复确认。向他人发送消息需要明确授权。缺失决定时先完成可审查准备，再询问缺失项。
- 可逆动作，例如编写代码、编辑笔记、拆分任务，应当继续，不要阻塞。
- 产品方向来自人类。执行不应阻塞。
