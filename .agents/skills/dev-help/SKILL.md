# 开发技能导航

先回答用户眼前的问题，再给一个贴合当前任务的示例和对应本地材料。用户只问怎么做时，交付说明与提示词；已经要求执行时，沿已授权目标继续，不重新要求用户发送一遍。

## 从实际需要开始

先依据当前消息和已有对话判断：需要配置、开始任务、选择方法、修正一次偏离，还是沉淀个人工作方式。仍无法判断且会改变答案时再问一个小问题，不先展开全目录。

完整使用方法见[帮助与分派](references/help-method.md)。给提示词时读[提示词写法](references/prompting.md)，选例子时读[完整提示词实例](references/recipes.md)。推荐名称前核实[能力地图](references/capabilities.md)中的职责，并检查该技能是否实际安装。

## 按需读指南

本包包含[完整十章指南](references/guide-index.md)，覆盖配置、任务分派、理解、设计、实施、验证交付、自主执行、24 条原则、个人适配与常见问题。它们是全文本地方法，不要求访问外部网站。只读本次问题需要的章节。

需要直接推进跨阶段开发时，优先使用已安装的 `dev-workflow`；阶段明确则选能力地图中的负责人。帮助只保存使用指南与提示词，不内嵌执行技能。通过宿主技能发现确认入口是否可读，按本次阶段读取，不加载整套资源。需要执行时调用对应技能；按实际安装情况读取相应入口。

## 交付

说明推荐的下一步及原因，最多给一个主要提示词示例，附可以打开的包内材料。用户要求完整地图时再展开。只对已经读取的内容作具体断言；新技能或项目自身约定与旧导航冲突时，核对当前文件后修正导航。

配置、开发方法与验证范围由任务决定。不默认指定模型，不把初始化变成所有任务的前置审批，不以绿色构建代替真实行为证据。长期知识仍沿用目标项目的 `.agents/dev/notes/` 等位置，帮助资料本身不接收项目状态。
