# 按真实能力适配开发宿主

每个会话首次使用跨宿主方法时，读取当前工具 schema、项目指令与实际目录。下表是能力对应关系，不是当前环境已安装某工具的声明。工具拒绝的字段或值不能传入；没有真实等价能力时说明限制。

## 工具

| 方法所需能力 | 适配方式 |
| --- | --- |
| 委派任务 | 使用当前实际提供的子智能体工具；可能叫 `Task`、`Agent` 或其他名称。没有则顺序执行相应视角。 |
| 询问用户 | 有结构化问题工具时按其真实选项数量与字段使用；非交互模式或工具缺失时用普通文字，只询问影响当前决策的缺口。 |
| 待办清单 | 有待办工具时可用；否则在回复或项目现有 Markdown 中保持简短列表，每阶段更新。 |
| 读取方法或技能 | 直接读取本包相对资源。其他技能按需调用；不假定某个斜杠命令或技能执行 API 一定可用。 |
| 搜索文件与文字 | 优先已有文件搜索能力或 `rg`；环境没有时使用可用替代，不虚构 `Grep`、`Glob`。 |

## 子智能体字段

| 请求含义 | 适配方式 |
| --- | --- |
| 通用执行者 | 选当前工具明确列出的通用类型，不在 `generalPurpose`、`general-purpose` 等拼写之间猜测。 |
| 专门审查者 | 只有类型已实际注册才传类型名；否则把本地审查说明作为任务提示交给通用执行者。 |
| 只读调查 | 使用真实只读限制；若只是提示约束，明确“不要修改文件”，隔离或记录前后状态，不把能运行终端的类型视为技术上只读。 |
| 允许编辑 | 明确可写路径及边界，先确认执行者确实有需要的工具、认证和共享资源。 |
| 独立云环境 | 当前工具确实提供时才使用；否则可用隔离 worktree，但不能声称本地 worktree 会在本机关机后继续。 |
| 本地环境 | 默认环境已满足时省略不支持字段，保留真实机器依赖。 |
| 指定基础分支 | 使用支持的字段，或在任务说明中明确起点并核对实际检出；不悄悄使用另一提交。 |
| 后台执行 | 只采用已公开的后台机制；明确是否需要等待、如何收到完成事件以及会话退出后是否存活。 |
| 恢复或跟进 | 了解当前工具的跟进语义，避免状态查询意外重启任务。没有恢复能力时，用已有结果和恢复说明开启新执行上下文。 |
| 附加文件 | 工具支持附件才用对应字段，否则给出执行者可访问的实际路径；文件系统不共享时提供必要内容。 |

## 模型

| 配置形式 | 适配方式 |
| --- | --- |
| 名称中带家族、版本、推理或速度 | 先核对实际已接受标识。宿主用独立 `model`、推理或速度字段时，按 schema 拆分，不猜版本和枚举。 |
| 当前宿主不提供的家族 | 不传不支持值。已允许回退时继承当前会话并说明；跨家族比较为任务必要条件时标记无法完成该比较。 |
| `auto` 或 `inherit-parent` | 在本地角色表中表示继承。调用时省略覆盖字段或采用宿主支持的继承方式，不原样传不存在的别名。 |
| 项目角色规则 | 从项目约定位置读取；缺失角色沿用当前宿主或项目默认。不能因为有 Markdown 文件就断言每个宿主会自动加载。 |
| 模型与推理分开记录 | 验证该模型和推理组合同时被当前工具接受，再生成调用参数。 |

## 配置角色规则

按 `dev-setup`（角色配置） 执行，并处理三类宿主差异：

- 检测：以实际调用 schema 和当前可用模型为依据，不把某个文档中的旧枚举当事实。
- 默认值：保留当前会话继承和用户现有覆盖；不存在的默认值不得强行映射为另一付费模型。
- 写入：项目内优先维护一份 Markdown。用户明确要求全局且宿主支持时，才写对应全局规则；有的宿主需要 frontmatter，有的不接受，按当前已验证格式生成。根指令只放短导航，不塞入整张角色表。

## 路径

| 资料类型 | 适配方式 |
| --- | --- |
| 安装技能 | 统一使用目标项目的 `.agents/skills/<domain>-<name>/`。不再按领域增加中间层，也不未经请求复制到其他宿主目录。 |
| 插件和工具注册 | 复用实际安装的插件和公开工具能力；不编辑缓存、伪造插件清单或把源仓库路径当宿主安装路径。 |
| 项目规则 | 先读现有 `AGENTS.md` 或宿主实际读取的项目文件；只加必要导航，不建立两套相互矛盾的规则。 |
| 技能参考资料 | 读取本包里的相对路径。离线已有的资料不为阅读而重新抓取外部来源。 |
| 会话记录 | 只读用户明确授权的当前工作区路径。不能从一份命名规则推断并扫描整个个人目录；确认记录中的任务或会话标识，不能仅以“最新文件”认定当前会话。 |

## 缺失的宿主专有功能

缺少可选能力时，用一行说明“未执行：步骤；原因”，继续不依赖它的工作。若核心完成条件依赖该能力，明确哪些结果无法成立，先完成可审查的部分；不得用占位符假装端点、密钥、部署或验证已经产生。

| 能力 | 实际替代与边界 |
| --- | --- |
| 定时任务、webhook 唤醒、秘密请求 | 已有真实替代且在授权范围内时采用；否则保留本地任务或配置草稿。不能承诺会话结束后自动继续，也不能索要秘密明文。 |
| 审查机器人 | 已存在的 PR 评论按普通审查线程处理。没有检查或机器人时，不空等、不自称已启用；可做当前有能力完成的独立审查。 |
| 云智能体 | 可用独立工作区替代代码隔离；云端机器、仪表盘和断网后持续运行等性质不能随之假定。 |
| 内置 PR 工具 | 使用已有代码托管连接器或已认证 CLI 等价操作。创建、提交、合并和发送消息仍遵守本次已授权范围；工具可用不等于动作已获授权。 |
