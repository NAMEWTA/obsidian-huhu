## 输出

### 发现的组件

关键类型、服务、类和抽象。每项给出名称、文件路径，以及一句话用途说明。

### 流程

逐步说明执行流程。每步写明运行哪个函数或方法、位于哪个文件、做什么、接着调用什么。包含步骤间流动的数据。

### 已读文件

列出探索期间读过的每个文件，便于讲解者引用。

### 边界

该子系统连接代码库其他部分的位置，以及输入和输出。

### 不明显的事项

任何意外、由历史原因导致或容易出错的地方；看起来应按一种方式工作，实际却按另一种方式工作。

### 未决问题

任何未能完整追踪或理解的部分。诚实说明缺口。
