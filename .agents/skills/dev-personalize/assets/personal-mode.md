# 项目工程方式

此文件是起草模板。复制到目标技能后替换名称、描述与正文，删除本说明。只保留已有事实支持的规则，不把以下标题全部填满。

## 回复

写实际偏好及适用场景，不写“沟通清晰”等默认常识。

## 理解与执行

写稳定的调查、委派和授权惯例；最新用户要求优先。

## 证明与交付

写用户认可的完成条件、证据与项目交付约定。

## 按需资料

仅链接随本技能一同提供的相对资源。项目事实指向实际项目证据，不能把模板示例当现状。
