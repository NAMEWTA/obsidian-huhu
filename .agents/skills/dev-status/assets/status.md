# 进展记录

回顾范围：用户指定任务或时间；否则本次请求之前的最后一条用户消息。

## 变化

按用户提出的事项写结果、用户影响和真实状态。状态使用完成、运行中、失败或未检查。引用已有证据，不为填满模板制造数量。

## 等待用户的决定

逐项说明决定、建议、依据、风险与必要前置条件；有实际链接时附链接。没有待决事项就明确写没有。

## 我可以继续的工作

只列当前授权下尚可自行完成的工作。独立回顾不借此启动新工作；既有任务中的状态追问结束后，继续原来已授权的工作。

## 证据与未知

记录数字与状态的来源、核对时间，以及尚无法确认的部分。短回复可不单设此节，把必要未知放在对应条目中。
