# 历史进展的取证资料

用户指定时间或主题且证据分散时，从`dev-learn`（完整背景取证）开始。只在本次授权的工作区与范围内检索；没有访问能力就标明缺口。这里的调查为进展报告提供依据，最终使用[进展回顾](status-report.md)组织变化与待决事项。

## 调查与综合

- `dev-why`（证据与可信度）：区分直接证据、推断和未知。
- `dev-why`（调查者简报）：给出本次时间、主题、代码锚点和允许读取的来源。
- `dev-why`（综合方法）：保留事实、反证、竞争解释和空结果，再提取报告所需结论。
- `dev-why`（来源选择）：依据真实连接器和读取能力选择下方手册。
- `dev-why`（事故与复盘背景）：主题涉及回退、复发错误或防御代码时使用。
- `dev-writing`（清晰写作）：写清已知结果、范围和下一步建议。

## 来源手册

- `dev-why`（版本控制与 PR 历史）
- `dev-why`（工单与问题记录）
- `dev-why`（长篇文档）
- `dev-why`（团队对话）
- `dev-why`（运行遥测）
- `dev-why`（错误历史）
- `dev-why`（产品分析记录）

每位调查者只读所负责来源。来源手册中的工具是具体示例，不代表当前环境已经接入；不得为了补齐报告扫描未授权账户或其他项目。
