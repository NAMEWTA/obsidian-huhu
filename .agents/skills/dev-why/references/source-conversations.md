# Slack 对话

## 如何搜索

Slack MCP 工具各不相同。先检查可用的 Slack MCP 及其工具 schema。若遇认证墙，按当前环境真实提供的授权能力处理，不调用不存在的认证工具。认证失败时停止，并报告缺口。

1. **按作者限定搜索。** 搜索 PR 作者在合并日期附近的消息。这能显著缩小范围，而且常有关键发现。
3. **搜索 PR URL。** 在评审或讨论 PR 时，Slack 经常会贴链接。搜索 PR URL，或只搜索 `/pull/<number>`。
4. **搜索错误字符串。** 如果代码处理某个特定错误，搜索该错误字符串，常能找到事故讨论串。

## 常见陷阱

- **频道考古的边界。** 很旧的消息可能因保留政策而消失。如果某个日期之前什么都找不到，注明保留期限断点。
- **未搜索的私信。** 很多决定发生在无法搜索的私信中。你会遗漏它们，这是已知限制。
- **把随口玩笑当作“决定”。** Slack 交流很随意。“哈哈，做就是了”不是一个决定，即便它出现在提交之前。寻找经过考虑的讨论。
- **单条消息脱离背景。** 不看讨论串，单条消息的含义常与完整上下文不同。始终获取讨论串。
- **认证失败。** 如果 MCP 没有认证，停止。不要编造发现。报告 Slack 无法搜索。
