# 交接方法

编写一份总结当前对话的交接文档，让一个全新的代理可以继续工作。一次性跨会话交接可用操作系统临时目录；需要持久恢复时统一保存到 `.agents/dev/changes/<日期-主题>/handoff.md`，引用已有任务的真实位置。不把项目进度写入技能安装目录。

在文档中加入“建议使用的技能”一节，列出下个代理应该优先读取哪些本地方法或已安装技能；未安装的可选技能不得成为恢复阻塞。

不要重复其他产物已经记录的内容，例如规格、计划、ADR、问题、提交和差异。使用实际存在的项目路径或已核实的任务地址 引用它们。

对 API 密钥、密码、个人身份信息等敏感内容进行脱敏。

如果用户传入参数，将其视为下个会话的重点描述，并据此调整文档。
