# UI-001 技术核对与复核

评估由本次 P owner 在任务/视觉评估后执行。浏览器为 Chrome 153.0.8010.47 headless，通过 CDP 打开本包实际 file 页面、点击控件、输入、发送键盘事件并截图；浏览器网络设为 offline。未使用生产 Vault 或真实 Provider。

## 发现与处理

- 首轮命令弹层的原生 Tab 行为不足以保证界面内循环，增加显式首尾焦点约束，并用实际 Tab/Escape、focus-visible 和焦点返回复核。
- 删除页面最小宽度，避免 200% 缩放后产生无意横向溢出；保留内部终端滚动。侧栏预览宽度处于继承范围内。
- 绑定分屏的明确目标，避免已有两个面板时“分屏显示第三个终端”仍显示旧对象；复核主控与第三个 Shell 同时出现且焦点保留。水平/垂直比例使用同一份状态。
- 邮箱计数按实际未确认消息计算；标注在本页内存中保存并可回读；原生历史继续按每条记录确定 Provider 与受管会话，不把不同历史都恢复到同一个示例 ID。
- 面板关闭和终端提交按钮的桌面命中区域补齐到 32px；窄屏主要按钮使用 44px。新建空 Space、明确库外授权和 Agent 停用后的拒绝路径均检查。
- 初轮自动化中两个失败来自测试条件：CDP Escape 缺 virtual key code，以及 C 隐藏侧栏仍断言省略宽度。已修正测试条件，未为这些误判改设计。

上述收尾保持用户选定的 A 布局、配色与交互方向，没有开启新一轮设计。浏览器最终证据绑定修正后的完整包摘要；选择确认原话与最终摘要之间的收尾说明见 approval-ui.md。

## 检查范围

每个候选和 final 均在 1440×1000 与 390×844 独立操作：命令搜索与弹层焦点、跨 Space 明确目标、提交/等待/读屏、只读历史、长中文、明暗主题、200% CSS zoom 和 reduced motion。final 另逐项覆盖 DESIGN 的 40 个页面状态及创建、分屏、关闭/重新显示、取消等待、停止取消、原生批准/拒绝、邮箱 read/ack、失败重试、恢复和网页独立性。实际观察记录见 observations.json。

comparison 两个尺寸实际打开，检查三候选链接、文字重排、键盘焦点、缩放和 reduced motion。13 张交付截图均实际打开核对，属于截图与状态观察，未进行真实触屏设备测试。辅助和主要文字、主按钮、三种状态色在明暗回退主题中共 14 组对比度已计算，结果见 contrast.json；这不是生产主题兼容认证。

## 资源与限制

运行依赖仅在 final/ 与 comparison/ 内，本地字体附完整许可。源代码块与 final 三文件逐字匹配，JavaScript 可解析，无浏览器控制台错误、无网络资源。HTML 原型不调用生产 API 或文件写入；Node 检查程序只连接独立的本机 CDP 并写 evidence。

只证明原型。没有测试真实 PTY、后台进程回收、原生审批协议、磁盘持久化、实际数据迁移、NativeHost 并发、生产内存或五平台。CSS zoom 是布局与可操作性模拟，不等同 OS/Obsidian 的每一种缩放实现。
