# T-25 data UI code candidate

数据页消费 `BotClient.profile.deletePreview/delete` 与
`BotClient.portable.export/importPreview/import`。删除区展示服务端返回的 token、revision、过期时间和全部分类，明确列出可保留的 memory ID；出现 `unknown-effects` 时保留核查提示并让服务端门禁阻止全清。破坏性命令必须经过 AlertDialog，确认内容包含 token、过期时间、预检分类计数和显式保留 ID。页面不直接删除客户端文件，也不声称删除 Provider 远端内容。

portable 区要求用户输入明确的 Bot、会话和记忆 ID；导出只显示服务端返回的 artifact 引用。导入只接受 artifact 引用，先请求预览，再逐项显示冲突 ID、revision 和 hash。每项映射必须由用户选择 keep/replace/copy，未选择时确认按钮保持禁用；页面说明导入身份不会继承权限或凭证，需要重新授权，不执行隐藏默认合并或自动导入。
