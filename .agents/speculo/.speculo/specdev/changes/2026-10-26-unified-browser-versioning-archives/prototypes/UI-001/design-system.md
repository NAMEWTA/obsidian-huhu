# UI-001：浏览器、版本历史与通用档案

本文件拥有检测、候选源码与验证证据；规则唯一属于 [change DESIGN](../../DESIGN.md)。所有演示内容为虚构本地夹具，不使用真实资料，不连接网页，不执行 Git 或档案写入。

## Project Evidence

- **目标与核心任务：** HUHU 桌面工作台；创建与维护项目档案、关联个人/企业、查看独立调研空间、比较笔记历史与安全恢复、配置表单和处理迁移。
- **平台与输入：** 桌面 Obsidian 的鼠标与键盘；390px 是窄叶子适配，不代表手机受管浏览器承诺。触摸仅做 Chrome 模拟验证。
- **证据模式：** 生产 UI 为 source-only；本包离线原型为 rendered。生产现状由代码证明，原型截图不冒充生产验收。
- **原权威：** 项目 UI Skill、docs/design-system.md 和组件；永久基线 owner 为 A。本包不复制第二套永久规范。
- **基线：** DESIGN-0001 / DS-001–DS-006，摘要在 change DESIGN 固定。
- **检测范围：** 工作台 shell、档案列表/详情、BrowserWorkspace、NoteReviewPage、共享 Button/Dialog、主题 token；无新宿主 View。不涉及 Agent/终端外观改造。

### Keep, Adjust, Replace, Add

| 动作 | 方案与依据 |
|---|---|
| 保留 | 图标轨/上下文栏/主区、原生主题语义、紧凑按钮、三宿主 View、原笔记编辑器。 |
| 调整 | 上下文栏按领域切换，详情表单与比较布局在窄叶子重排。 |
| 替换 | 无全局视觉替换；不采用模板的品牌色、额外状态栏或移动底部导航。 |
| 补齐 | 通用档案字段/表单/关系、迁移反馈；历史采集设置；跨域恢复拒绝；浏览器未知结果与身份导入边界。 |

检测结论：hybrid，以 HUHU 高密度工作台为主，档案资料区适度留白；中性表面与宿主强调色。模板只提供结构。未复制上游 HTML、图片、图标或字体，简单 SVG 为本包绘制；使用系统字体，无外部资源许可新增。

## Candidate Composition

| 候选 | 主模板 / 辅助职责 | 差异与代价 | 状态 |
|---|---|---|---|
| A（推荐） | dense-ide 的资源与编辑区；HUHU 为主视觉 | 对象列表 → 详情，切换代价最低；长表单需分组 | 待确认 |
| B | enterprise-data 的表格决策；HUHU 为主视觉 | 先比较多行，再打开详情；窄屏表格局部滚动 | 待确认 |
| C | local-first-content 的阅读组织；HUHU 为主视觉 | 正文先行，右侧相关内容目录；批量操作效率较低 | 待确认 |

本轮类型树与类型点击行为是共同硬约束，不再提供互斥导航方案。三个历史详情候选已共同更新类型树，候选入口从同一实例详情打开，仅供比较详情组织；final 从类型总览打开，可由列表/卡片或树进入详情。候选数采用缺省 3，无用户覆盖。优先级：用户已确认 Spec/ADR → DESIGN-0001 → 功能模板。外部品牌和模板任意尺寸不覆盖项目基线；仅借鉴结构，不声称使用外部产品的完整设计系统。
