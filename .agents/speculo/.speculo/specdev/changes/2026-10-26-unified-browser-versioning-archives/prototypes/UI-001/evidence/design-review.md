# 修订 2：档案任务与视觉复核

用户方向来自 SRC-007：继承当前档案类型树，点击类型显示其全部实例列表/卡片，显示字段由类型勾选，默认创建/更新时间。该方向已确定，不再重开导航风格比较；当前 HTML 尚未被整体批准。

核对了实际 workbench.ts、surface.tsx、panel-state.ts 与 archives-panel.dom.test.tsx：现有个人/企业本来就是类型树，名字与展开箭头职责不同，列表/卡片和返回状态保留也已存在。上一版检测没有落实这些已有事实。本轮移除平铺类型/最近访问混杂导航，final 从类型总览开始，点击实例才进入详情。

宽屏列表展示 3 个项目的名称、编号、阶段与两个时间；切卡片后使用同一组字段。类型设置用明确的复选框；取消显示只隐藏摘要，不删除值。个人/企业/新类型都由同一树组织，新建空类型可继续创建实例。项目总览、卡片、字段设置与窄屏 Sheet 截图已打开确认；其余当前截图通过修订 2 contact 索引逐格核对。

层级现在只有类型 → 实例 → 详情，类型列表不混入某个实例的大表单。树选择同步右侧，折叠不跳转，返回保留查询和布局。列表窄屏采用可聚焦且有名称的局部滚动；卡片单列，默认时间不被隐藏。列表/卡片是同一个类型总览的显示方式，不要求用户在两种产品架构间做选择。

遗留三个候选只保留详情组织差异，均遵守相同类型树；当前 final 采用 A 的详情组织。复核由当前 Agent 单独开展，未宣称独立外部评审或生产宿主验收。大规模虚拟树、真实迁移、档案元数据持久化仍由实施阶段证明。
