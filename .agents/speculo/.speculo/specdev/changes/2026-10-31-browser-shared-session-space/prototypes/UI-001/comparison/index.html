一个设计体系，三种信息布局

三者都继承 DESIGN-0002 与用户指定的 UI-001：圆角、控件、留白、主题和状态语义不变。差异只在空间导航和任务信息的位置。推荐不是批准。

A · 完整工作台（推荐）

保留 Space 侧栏与当前页面；控制条紧邻网页。适合日常人机交替操作。窄窗口使用导航弹层。

打开可操作候选 A →

B · 紧凑空间导航

隐藏常驻 Space 栏，使用页头选择器，把宽度让给网页。适合小窗口；空间切换需要额外一次动作。

打开可操作候选 B →

C · 任务摘要并列

宽窗口常驻任务和授权摘要，方便长任务观察；占用网页宽度，窄屏退为下方摘要。

打开可操作候选 C →

各候选含同一虚构内容与完整模拟流程。没有网络、真实 guest、Cookie 或磁盘操作。源说明与实际离线检查见相邻 design-system.md / evidence。
