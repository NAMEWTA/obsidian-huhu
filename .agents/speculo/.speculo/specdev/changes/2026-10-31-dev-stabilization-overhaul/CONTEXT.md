# dev 收口：生命周期、持久性与验收语言

**停止请求已接收**：运行时已关闭准入并开始停止；不表示执行器、持久化或资源已经结束。
_Avoid_: 已停止、已关闭

**执行器已排空**：所有生产者已收敛，不再有进行中的执行产生新事实。
_Avoid_: 停止成功

**持久化已完成**：关停所需的 WAL 同步或持久屏障已返回成功；按 ADR-027 的故障模型解释。
_Avoid_: 已刷盘（不说明故障模型时）

**Profile 已释放**：Profile 锁与文件资源已解除，宿主才可以重开、删除临时目录或再次获取该 Profile。
_Avoid_: 关闭完成

**业务提交**：事务 COMMIT 成功即成立的业务事实；之后的维护失败不能改写它，也不能触发业务重试。
_Avoid_: 写入完成（与检查点混用时）

**检查点维护**：由存储 adapter 拥有、有界且可合并的 WAL 维护工作，不由某个业务调用承担。
_Avoid_: 提交后清理

**启动关键路径**：工作台、首页基本结构和本地交互可用之前必须完成的工作；可选账号恢复、外部探测与非关键网络任务不在其中。
_Avoid_: 初始化

**显示名称**：经 `t()` 本地化、随界面语言变化的名称；不作主键、关系目标或存储路径。
_Avoid_: 名字（不区分显示/身份时）

**稳定身份**：内置类型、字段或对象的机器 ID，不随语言或用户改名变化。
_Avoid_: 名称 ID

**兼容层**：为旧接口、旧格式或旧别名长期保留的分支、双读双写或副本；本 change 不保留。
_Avoid_: 过渡实现

**证据等级**：源码确认的机制、已报告现象、待复现假设、计划方案、已运行验证五类；验收只接受已运行验证。
_Avoid_: 已确认（不注明等级时）

**运行时名称快照**：自动化运行发生时记录的名称，作为该次通知的主文案；当前名称在详情中按稳定身份解析。
_Avoid_: 自动化名称（不区分快照与当前时）

**用户真机验收**：在真实 Obsidian、Windows/macOS 实机或虚拟机骤停环境下由用户本人完成的验收；不由 agent 执行或跟踪，CI 与 DOM 结果不能替代。
_Avoid_: 平台验证（指 CI runner 时）

**Browser 冻结**：LOG-018 起暂停 HUHU Browser 及其集成面的所有开发与修复，具体边界见 `<Path>{roots.state}/specdev/changes/{change}/execution-boundaries.md</Path>`；独立 Chrome/Chromium UI 验证工具不属于冻结产品。冻结范围不计为本 change 已完成，也不因其他实施授权自动恢复。
_Avoid_: 全插件已迁移（Browser 仍冻结时）

**合同集成批次**：允许多票分别实现同一合同的生产者和消费者，但完整更新、联合验证后才进入 dev；票级检查不等于整链通过。
_Avoid_: 同一票（实际分成 T-04/T-06 时）

**fixture 性能趋势**：stub 宿主与独立 Chromium 中真实非 Browser 模块/组件的可重复测量，注明边界和口径；不是 Obsidian 真机性能。
_Avoid_: 插件启动实测（只运行 fixture 时）

**设计发布例外**：DESIGN-0002 按用户已批准的实施前发布指令人工落盘；标准 promotion 预检拒绝的事实保留。这是批准的时点例外，不是标准发布工具成功。
