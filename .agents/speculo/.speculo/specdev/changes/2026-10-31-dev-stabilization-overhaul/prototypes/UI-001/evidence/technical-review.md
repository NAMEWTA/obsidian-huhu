原执行者检查记录（以下为初版记录；不代表本轮重新全跑，toast 与嵌入导航遗漏由下方复核纠正）：
- 无横向溢出：每页每视口每主题；局部滚动区（表格、标签条、对话框）除外。
- 键盘：Tab 顺序至少 5 个不同可聚焦元素，焦点环为 3px 实线，元素可见；Tabs 左右方向键，Menu 方向键，Dialog 焦点约束、Esc 关闭并回到触发器。
- 长文本：打开长文本模式后复查溢出；候选页自带 100 字符以上无空格名称。
- 200% 缩放：以 CSS 视口减半加 DSF 2 近似（390 的情况取 320 下限）；页面也提供 CSS zoom 开关，未用于判定。
- reduced-motion：模拟 prefers-reduced-motion，无无限运行动画，过渡时长为 0。
- 状态：六页共 50 个状态逐一用脚本操作或断言（hover 为真实鼠标事件，颜色变化且尺寸不变；busy 重复点击仅提交一次；日期完整显示；通知名称快照、改名、删除、空名称、失败持久；终端状态切换后窗格节点、输入、滚动、选择保持且创建次数为 1；区域无 title/aria-label，空白处悬停无提示）。
- 输入法：用合成的 composition 与 isComposing 事件验证，不是真实输入法。
- 对比度（预览回退色，WCAG 公式）：亮色正文 16.5、弱化文字 6.8、主按钮 6.3、控件边框 3.66、徽标 5.0 至 6.5；暗色正文 14.0、弱化 7.2、控件边框 5.1、徽标 6.3 至 8.9；终端文字 13.6；候选 B、C 的主要组合均大于 4.5。生产色以 Obsidian 主题为准，未测。
