# 决定、待确认与不得伪装的完成

## 已由 Issue 和本轮用户决定

Pi 官方 SDK 是唯一 harness；全部新产品/编排 TypeScript；独立 huhubot 模块；启动服务而非打开页面启动；UI 仅 Obsidian；无 Go/Eino/HAP 兼容、旧存储自动迁移或双引擎。旧代码可删、用户旧数据不可自动删。复用同一 DESIGN-0002 / UI-001 A 方向，不再做三套新品牌风格。原型中的圆润来自 6/8/12/14px 分级，不把一切做成胶囊。

## 本轮唯一需要用户评审的产品问题

**这份新 Bot 原型的信息架构和关键交互，是否可以作为本 change 的 UI 意图？** 评审入口覆盖会话、审批、三种关系视图、记忆、Bot 配置、浏览器协作、自动化与数据恢复。确认应绑定本次文件 digest，不把已有 UI-001 的批准移植到新文件。未确认时相关票保持 draft。

## 不要求用户猜的技术问题

P0 实测 utilityProcess/Node ≥22.19.0/ABI/发行资源；验证凭据适配与真实本地根路径；检查完整引用图；验证 Pi 的 MCP/tool-search/codemode 能否全部过 Gateway。它们都是执行者应查证的事实。失败后出现真实取舍才进入下一轮 Grill。

MCP 存在版本漂移：Issue 用 2025-11-25 作为稳定协议参考；2026-10-31 查到官方 v2 文档已讨论 2026-07-28。保留 Issue 原文，不静默升级，也不把 2025 版宣称为“最新”。T-20 固定 SDK 精确版本、协商协议、客户端互操作矩阵；产品只选一套 client owner 与单一 server transport。
