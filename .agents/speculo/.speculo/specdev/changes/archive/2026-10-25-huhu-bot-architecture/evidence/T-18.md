# T-18 portable import/export

本窗口实现了版本化 `huhu-portable` JSON 包合同：显式白名单只包含 Bot 配置摘要、公共会话消息和记忆内容；凭证引用、Grant、Approval、Checkpoint、租约、队列、Run/执行身份没有序列化字段。包包含 manifest、逐项 SHA-256 与整体 hash；解码拒绝未知字段、尾随数据、超限、篡改和不兼容版本。

应用层提供 `Build`、`PreviewImport` 和需显式确认的事务 `Import`。预览为 Bot/Session/Memory 生成新 ID 映射，报告同名/命名空间冲突，并把来源标记为 `SOURCE_GRANT_REQUIRED`。导入通过 `Sink.Begin` / `Transaction`，任一写入或提交失败均回滚；导入本身没有模型或后台作业入口。

文件 adapter 使用 0600 临时文件、原子 no-overwrite 发布、symlink/类型/大小检查和 fsync；导入回读同一 hash 合同。

## Core assembly addendum (2026-10-27)

T-18 现在已由 Core 具体装配：`bootstrap.OpenWithOptions` 将已有 `base.Store`、Profile directory 下的 `portable/artifacts` 文件适配器和 SQLite portable repository 组装为 `application/data/portable.Service`，并通过 `Core.Portable` 暴露给 transport 组合。Core 只持有 application API；SQL、文件路径和包编码仍留在 outbound adapter。

实现的可移植子集是 agents、sessions 和 active memories。sessions 通过 `BeginForPrincipal` 绑定调用方 principal；memory source 只携带稳定引用，不导出 host lease 或 grant。凭证引用、Grant、Approval、Checkpoint、lease、queue、run/执行状态没有字段。模型绑定只有完整的 model/provider/endpoint/protocol 才允许导出；缺字段显式返回 `CAPABILITY_DENIED/PORTABLE_MODEL_BINDING_UNSUPPORTED`。遗忘记忆显式返回 `CAPABILITY_DENIED/PORTABLE_FORGOTTEN_MEMORY_UNSUPPORTED`。所有写入在一个 SQLite transaction 内完成，提交前不会唤醒模型或后台作业。
