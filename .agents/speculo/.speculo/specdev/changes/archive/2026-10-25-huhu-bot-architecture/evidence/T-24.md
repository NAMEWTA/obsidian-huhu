# T-24 memory UI code candidate

实现了 Bot、短期和全局命名空间的记忆页面组件。页面从 `BotClient.memory.list` 读取权威对象，显示作用域、修订、来源、来源性质、固定状态和自动维护资格；组件不从本地 UI store 推断持久结果。固定、纠正、遗忘和自动维护操作均携带当前 namespace 与 expected revision，失败保留错误和输入。

全局提案单独显示为 pending preview，只有用户点击确认或拒绝才调用 `memory.resolveGlobal`；待确认内容不会显示为已生效记忆。页面保持可键盘操作的真实按钮/文本框、焦点环和窄屏换行，敏感正文只在后端允许的作用域内渲染来源与当前条目。
