# T-26 code-level evidence

新增固定本地负载和脱敏诊断回路：

- `native/huhubot/tests/contract/performance/performance_test.go` 固定 100 个 HAP frame decode 样本，记录 OS/架构/Go 版本、frame p50/p95 和 stdio 32 帧/字节边界；同时序列化诊断结果并拒绝正文、prompt、credential、secret 等私有字段。
- `scripts/bench-huhu-bot.mjs` 测量固定长度历史的本地 JSON round-trip，输出环境、样本、历史长度、p50/p95 和显式队列上限；默认 `provider: not-run`，不访问网络。
- `docs/huhu-bot-performance.md` 说明可复跑命令和不得把本地结果解释为 Provider 网络性能承诺。

```text
GOTOOLCHAIN=local go test ./tests/contract/performance/... -count=1  # exit 0
GOTOOLCHAIN=local go vet ./internal/... ./cmd/... ./tests/contract/performance/... ./tests/contract/portable/...  # exit 0
pnpm run bench:huhu-bot  # exit 0; deterministic-local, provider=not-run
```

当前不宣称真实 Provider、Obsidian 或目标系统 p95；这些测量由用户自己的 endpoint/model/凭证和目标环境验收完成。
