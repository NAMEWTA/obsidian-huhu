# 版本管理领域

来源为 [Issue #2 冻结正文](../sources/issue-2-body.md) 的比较模型、恢复协议、本地历史与存储合同；跨档案边界见 [ADR-002](../ADR.md#adr-002-受管档案历史覆盖由档案-owner-预检)。

**RevisionRef**：指定可解析内容来源的版本引用，区分 Git 提交、本地历史、恢复检查点与编辑缓冲。
_Avoid_: 所有版本都称为 Git 提交。

**TextSnapshot**：正文与格式信息的固定快照，包含内容身份；不随原笔记继续编辑而暗中变化。
_Avoid_: 比较时每次读取当前正文而称为同一快照。

**比较会话**：固定 A/B 两端及来源笔记/窗口的审阅上下文；显式刷新才重新捕获 B。
_Avoid_: 全局活动笔记即任意会话的恢复目标。

**恢复检查点**：覆盖前保存的恢复材料及相关阶段记录；未闭合恢复仍引用的对象不可按普通缓存回收。
_Avoid_: 可任意删除的预览缓存。

**自动本地历史**：内容变化时按策略采样形成的设备侧版本来源，与 Git 提交、强制恢复前检查点分别管理。
_Avoid_: 自动提交用户分支，或逐键日志。

**恢复回执**：记录已核验效果与后续撤销前提的持久结果；失败和未知结果不能冒充已完成回执。
_Avoid_: 命令返回即正文与 Git 状态已核验。

**同步 hold**：恢复后仍持久阻止 HUHU 自动提交、拉取和推送的状态，由用户明确处理后解除。
_Avoid_: 自动恢复网络同步，或全局锁住外部 Git 工具。

**恢复为副本**：创建唯一名称的新笔记，保留原笔记；历史附件和批注消息不隐式复制或回滚。
_Avoid_: 整个历史文件环境的完整克隆。

**受保护历史对象**：仍被未闭合恢复或仍承诺可撤销操作引用的快照对象；期限和配额清理不能删除它。依据 [ADR-003](../ADR.md#adr-003-自动本地历史显式启用并保护恢复依据)。
_Avoid_: 超过保留期就无条件可删除。

**采集暂停**：因空间不足等可见原因停止生成新的自动本地历史，已存在的恢复依据保持；不豁免正文覆盖前必须成功写入检查点的要求。
_Avoid_: 采集暂停等于历史被清空或恢复可以跳过检查点。
