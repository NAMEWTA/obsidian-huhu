# dev 稳定化收口：产品线与兼容术语

类型：domain-terms

适用范围：2026-10-31-dev-stabilization-overhaul 的已采纳领域合同；与现行代码一致，实现与验收状态沿来源分别判断。

来源：CONTEXT.md（`changes/archive/2026-10-31-dev-stabilization-overhaul/CONTEXT.md`，纯文本路径，归档移动前链接不可解析）（原始字节 SHA-256 `39872bb81a239fdbd755595f1504838849260e6560b6ffb85ba460e390579567`，归档后位置）；关联[决策](../adr/2026-11-04-dev-stabilization-overhaul.md)。提升日期：2026-11-04；网关 owner：specdev/archive-and-consolidate，host:claude-code/root。来源术语中关于 Runner 停止阶段、检查点维护、Browser 冻结、设计发布例外、证据等级与验收流程的条目属于单次 change 的过程语言或已随 huhubot 删除，不提升。

**产品线收缩**：browser、huhubot、superbot 从 HUHU 整体物理删除，不再规划其任何优化；与其无关的稳定化与 UI 工作不受影响。
_Avoid_: 暂停、冻结、隐藏入口（指这三块时）

**预发布旧数据**：正式发布前开发期产生的旧目录、旧设置、旧格式、旧布局、旧会话与旧集成凭据；不是受支持版本，无保留、迁移、回读或兼容义务，遇到时按“无效/损坏/不可识别”处理且不改写文件。首次正式发布后此义务不再自动免除。
_Avoid_: 历史版本、待迁移数据

**兼容层**：为旧接口、旧格式或旧别名长期保留的分支、双读双写或副本；发布前不保留。名称含 legacy 的现行逻辑（如终端 legacy 键盘编码、评论“无颜色”的 `legacy` 颜色 id）不是兼容层。
_Avoid_: 过渡实现

**网页快捷卡**：Home 卡片类型 `web`，点击在系统默认浏览器打开一个网址；不依赖已删除的浏览器模块。区别于已删除的 Home 网页嵌入分区。
_Avoid_: 浏览器模块、网页分区

**启动关键路径**：工作台、首页基本结构和本地交互可用之前必须完成的工作；可选账号恢复、外部探测与非关键网络任务不在其中。
_Avoid_: 初始化

**显示名称**：经 `t()` 本地化、随界面语言变化的名称；不作主键、关系目标或存储路径。
_Avoid_: 名字（不区分显示/身份时）

**稳定身份**：内置类型、字段或对象的机器 ID，不随语言或用户改名变化。
_Avoid_: 名称 ID

**运行时名称快照**：自动化运行发生时记录的名称，作为该次通知的主文案；当前名称在详情中按稳定身份解析。
_Avoid_: 自动化名称（不区分快照与当前时）

**Hook 发布序号（seq）**：状态 Hook 发布者写入引用的单调时钟序号，是同一 scope 内事件投递顺序的唯一依据；槽位号不承载顺序。
_Avoid_: 槽位顺序、到达顺序
