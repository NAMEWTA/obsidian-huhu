## 验证边界

构建、自动化测试、原生 helper 和真实 Obsidian 验收分别证明不同层面的行为。每次交付应报告实际验证的平台和场景；Windows CI 不等于 Windows 图形宿主实测，原生 Hook 测试不等于真实服务商登录或模型执行。最低 Obsidian 版本、移动端、不同主题、真实账号和长期运行不因一次检查而获得完整保证。
