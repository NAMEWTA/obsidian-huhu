# 外观

工作台 **设置 → 外观** 管理 Obsidian 界面、笔记与 HUHU 页面。设置即时应用到主窗口和弹出窗口，保存在 `.huhu/config/settings.json` 的 `theme` 命名空间。也可从 Obsidian **设置 → HUHU → 打开设置** 进入。

界面主题决定宿主与 HUHU 的表面和控件；编辑器样式决定笔记的排版、内容块和配色；个人字体、字号、行高、标题与加粗选择保留自己的优先级。看板仍共享全局颜色。

## 选择与优先级

| 选择 | 实际效果 |
| --- | --- |
| 默认界面 + 跟随主题编辑器 + 默认排版 | 不添加外观覆盖类和变量，继续使用当前 Obsidian 或社区主题 |
| SuliWorld 界面 + 跟随主题 | 使用 SuliWorld 界面及配套笔记风格、默认字体 |
| SuliWorld 界面 + GitHub 编辑器 | 界面保留 SuliWorld，笔记使用 GitHub 文档结构 |
| 默认界面 + SuliWorld/GitHub 编辑器 | 保留宿主界面，采用独立笔记风格 |
| 明确选择字体、字号、行高或标题/加粗 | 更换主题时保留，不改写成新主题默认值 |
| Obsidian 自带外观中的显式字体 | 优先于 HUHU 推荐字体和字体选择，包含 HUHU 界面与等宽字体桥 |

“跟随主题”是持久设置，不会被解析器改写为具体编辑器 ID。“使用风格默认”只在运行时决定有效装饰。标题选择“强调”或“朴素”后，不再叠加 SuliWorld/GitHub 默认标题装饰；独立加粗设置仍生效。外观页显示当前是跟随还是独立选择。

色卡跟随所选 SuliWorld Cream/Forest 变体，并展示亮暗小型标签结构；阅读样例包含长标题和固定标签，便于核对标签高度、文字对齐及图标。**阅读样例** 使用当前窗口加载的同一份样式表、同一主题解析器和 Obsidian `MarkdownRenderer`：先在所属宿主 Document 的分离容器中渲染，再把静态只读内容复制到无脚本 iframe，呈现标题、引用、五类提示块、代码、表格、任务、标签、属性、图片和嵌入。可以仅在预览中切换亮暗和手机宽度，不改工作区明暗或设置。样例位于无脚本 iframe 内；链接不导航，任务不可写入，不引用库内文件，也不加载外部样例资源。这里展示阅读视图，不能替代实时预览和源码模式验收。

## 精选入口与旧预设

界面首屏保留六项：默认、SuliWorld、Pearl、Claude Code、护眼绿、自定义。编辑器首屏保留五项：跟随主题、SuliWorld、GitHub、Claude Code、护眼绿。其他选择收进“更多界面配色”和“更多编辑器配色”。命令 `HUHU: 切换到下一个主题` 使用六个精选入口；当前为附加配色时，下一次回到默认项。

这次收敛的是入口层级。全部原有 ID 继续可选、可读取、可导入；已保存的附加配色会在选择框显示。没有真实宿主的同内容对照证据时，不把相近名称当作相同效果，也不删除 ID 后让设置悄悄回退。

## SuliWorld

固定参考为 [SuliWorld `bb73ca6`](https://github.com/sulistef/obsidian-suliworld/tree/bb73ca60dbc1169eb8d4c81fefb0c721ff7faf42)，原作者 Stéphane Sulikowski。实现按 HUHU 语义变量、窗口生命周期和个人设置适配。

| 部位 | 实现 |
| --- | --- |
| Cream 亮色 | 奶油纸面、白色侧栏、森林绿选中、胶囊页签、橙色细节 |
| Forest 亮色 | 奶油正文，原生侧栏/工具带及 HUHU 导航侧栏深绿；活动页签橙色指示线 |
| 暗色 | 暖黑页面与暖棕黑表面，默认仅桌面显示圆角浮动窗格 |
| 界面 | 页签、侧栏条目、搜索结果、输入/按钮圆角、菜单/弹窗、焦点与语义状态使用协调的表面关系 |
| 标题 | H1 轻量大标题及细线，H2 橙色标记，H3 绿色，H4 桃色标签，H5 短横，H6 紧凑；标题内斜体使用展示字体和橙色 |
| 引用与提示块 | 桃色圆角引文；蓝、薄荷、桃、淡紫、浅黄语义提示块，图标/标题/内容协调 |
| 代码 | 行内代码与深色块分开；代码块亮暗均为深色表面、本地语法色、横向滚动和可见复制按钮 |
| 嵌入 | 深绿笔记卡片；标题、正文、链接、图标采用所在表面的浅色前景 |
| 其他内容 | 表格细横线、列表/标准任务、胶囊标签和属性、分隔线、高亮、图片圆角与链接标记 |

四个主题偏好：`suliworldVariant` 为 `cream`/`forest`；`suliworldCards` 为 `dark`/`always`/`never`；`suliworldPlainQuotes` 和 `suliworldPlainEmbeds` 为布尔值。浮动卡片默认仅暗色桌面启用；移动端不使用桌面窗格间隙。朴素引用用强调边框，朴素嵌入用淡边框。未启用的专属选项保留到下次使用。

Forest 的侧栏拥有独立前景、次要文字、悬停/选中前景和边框。一般 `muted` 表面仍是浅色，日历、档案和表单不需要识别主题 ID；侧栏内文字、图标、代码和状态使用局部语义变量。看笔记导航器以自身表面标记绑定这些变量，移到中央页或独立窗口后仍保留可读的日历正文、状态与输入控件，不改变相邻笔记的纸色表面。弹层使用所属窗口的公共 Portal，保留自己的背景/前景配对，避免继承错误的看板或侧栏颜色。

结构装饰主要作用于阅读与实时预览。源码保留 Markdown 标记、光标、选区和原生行测量，不隐藏语法。上游默认关闭的首字下沉未引入；五组字体精简为实际使用的默认亮暗搭配，个人字体选择继续可用。

主题不会改写笔记、任务标记、属性或文件位置。标准任务继续沿用空格、`x`、`X` 的原语义和宿主勾选操作。没有移植 Bullet Journal 特殊字符的状态判定或禁止点击行为。

## GitHub 编辑器

现有 `github` ID 原地升级，固定参考为 [GitHub Theme `0ec83a8`](https://github.com/krios2146/obsidian-theme-github/tree/0ec83a88de1161ed0311f76b2e962b6a233121da)，原作者 Vladimir Kidyaev。

H1/H2 使用细分隔线，标题比例、段落和列表间距保持文档节奏。行内代码有紧凑字号、留白和圆角；代码块采用亮暗独立表面、语法色、长行滚动和复制按钮。表格提供表头、单元格边框、留白、隔行底色与独立横向滚动。引用/Callout 使用边线，链接、任务和分隔线保持一致。

“强调”或“朴素”标题替代 GitHub 默认装饰，不叠加双重边框。没有新增 GitHub 全局界面主题，也没有引入 Kanban 插件或 GitHub Projects 功能。

## 字体与排版

| 设置 | 选项 |
| --- | --- |
| 界面字体 | 风格默认、跟随 Obsidian、Geist、Inter、系统界面字体、自定义 |
| 正文字体 | 风格默认、无衬线、衬线、楷体、自定义 |
| 等宽字体 | 风格默认、JetBrains Mono、Fira Code、Cascadia Code、SF Mono、自定义 |
| 笔记文字大小 | 12–24 px；0/默认沿用 Obsidian，仅作用于笔记 |
| 阅读行高 | 1.2–2.2；0/默认使用风格值，显式数值优先 |

SuliWorld 默认亮色为 **Outfit × Newsreader**，暗色为 **Manrope × Instrument Serif**，代码为 **iA Writer Duo**。只内置七个实际使用文件：Outfit/Manrope 正体可变字重，Newsreader/Instrument Serif 展示斜体，iA Writer Duo 正体/斜体/粗体。字体使用 HUHU 专用 CSS 家族别名，原二进制不变；构建时内嵌，`font-display: swap`，运行时不下载。完整 OFL 和版权在 `src/theme/fonts/LICENSE.txt`，清单在 `faces.json`。

上游默认字体主要是 Latin 子集，并不包含完整中文。正文回退到 PingFang SC、Hiragino Sans GB、Microsoft YaHei、Noto Sans CJK/SC 与系统无衬线；展示字体回退到 Songti SC、Source Han Serif SC、Noto Serif CJK/SC；等宽回退到 Sarasa Mono SC、Noto Sans Mono CJK SC 与系统等宽。实际回退取决于设备字体，中文标点、混排、长标题与代码需在目标设备检查。

宿主字体覆盖作为完整字体列表的首项，后续保留 HUHU 所选字体和 CJK/系统回退；缺省或不存在的字体不会截断整条回退列表。明确选择其他字体后，不再注入 SuliWorld 推荐展示字体，标题/引用使用个人字体；Obsidian 显式字体同样优先。自定义列表保留字母、数字、空格和 `,'".-_`，补系统回退。除 Geist 和 SuliWorld 默认字体外，选项引用设备已安装字体。终端字体仍单独管理。

## 复制、粘贴与重置

- **复制设置**导出 `kind: "huhu-appearance"`、`version: 2`，含全部外观字段。
- **粘贴设置**接受第 1/2 版；第 1 版原 ID 原样保留，缺少的 SuliWorld 字段补默认。未知版本、界面/编辑器 ID 或无效包络报错，现有设置不变。
- **恢复当前风格选项**恢复标题/加粗和当前启用的 SuliWorld 专属选项；保留风格、自定义颜色、字体、字号、行高及未启用风格偏好。
- **重置外观**恢复整个 `theme` 命名空间，包括字体和先前保存的 SuliWorld 选项。

## 与宿主、看板共存

默认界面保持宿主变量。完整界面主题只在相应类存在时接管变量和原生选择器；用户 CSS 片段仍按宿主层叠工作，不修改社区主题文件。关闭/卸载时撤除所有窗口的主题类和内联变量；已存在及新开的弹出窗口都应用当前设置。

看板外观工作室仍负责背景图、暗化、模糊、透明度、卡片圆角和局部字号，保存在 `home` 设置。全局外观提供颜色和默认样式，不覆盖工作室局部装饰。布局见[看板](dashboard.md#配色与外观)。日历、档案等组件只消费公共语义变量，不依赖 `--db-*` 或主题分支。

## 维护与验收

来源和许可见 [SuliWorld](third-party/suliworld.md)、[GitHub Theme](third-party/github-theme.md)。dbx 与既有色盘的原归属保留。

`src/theme/presets.test.ts` 保留原对比度门槛，增加 Forest 混合表面、五类提示块、引用/标签/标题块、深色代码、绿色嵌入及 GitHub 实际代码表面检查。默认主正文至少 7:1，普通文字至少 4.5:1；任务标记/弱化装饰原门槛为 3:1。数值检查只说明颜色配对可读，不等于渲染验收。

解析器、导入、局部/全量重置、多窗口撤除、预览隔离与延迟清理有自动化测试。`suliworld-scope.dom.test.tsx` 使用实际主题 CSS 检查导航器从侧栏移到中央容器、另一个 Document 后的局部颜色作用域，以及相邻笔记和公共 Portal 未受影响。真实宿主验收使用 `scripts/obsidian-acceptance/theme-matrix.mjs`。本轮已在 Linux Obsidian 1.13.7 的默认宿主与 Minimal 9.0.2 下验证全部预设亮暗、Cream/Forest/暗色、SuliWorld × GitHub、阅读/实时预览/源码、Forest 导航器侧栏/中央页/弹出窗口及月份弹层、字体覆盖与重置撤除；真实样例在 1100/820/480 宽度可见，预览控件不改宿主设置，笔记内容保持不变。物理移动设备、中文输入法、页签拖动/分栏及第三方后处理器的完整组合仍需目标设备验收，桌面宽度模拟和 DOM 测试不替代这些边界。
