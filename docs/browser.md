# 浏览器标签

浏览器标签由 Browser 模块独立承载。在 **设置 → 常规 → 功能模块** 中开启“浏览器”后，可从浏览器工作台页面打开网址或搜索词；开启“智能体”时也能在 Agent 的「+」菜单中把它放入终端布局并分屏。共享布局 owner 不依赖 Agent 生命周期，因此关闭 Agent、没有 Space 时网页仍可打开和恢复。内置网页仅支持桌面版 Obsidian。

## 地址与导航

地址栏接受 HTTP、HTTPS、本地绝对路径与 `file:` 地址。`localhost`、回环地址和 IPv6 使用 HTTP；域名和“主机:端口”使用 HTTPS。带用户名密码的地址及其他协议会被拒绝。非网址文字交给 Google、Bing、百度、DuckDuckGo 或自定义搜索模板；自定义模板必须使用 HTTPS 并包含 `%s`。

工具栏提供后退、前进、刷新／停止、站点信息、元素抓取、标注、截图绘制、开发者工具和系统浏览器入口。窄分屏把右侧工具收入“更多操作”。刷新按钮右键可强制刷新。地址建议包括最近 500 条历史和已打开标签，支持方向键、Enter、Tab 与 Esc。

`Ctrl/Cmd+L` 聚焦地址，`Ctrl/Cmd+F` 查找，Enter／Shift+Enter 前后查找，Esc 关闭查找并回到网页。`Ctrl/Cmd+R` 刷新、加 Shift 忽略缓存；加号、减号、0 调整或恢复缩放。缩放范围为 25%～300%。更多菜单提供视口模拟与可见区域／整页截图。

普通标签切换、同一窗口中的分屏与拖放只同步网页保留层的位置，不移动 `<webview>` 的父节点，因此保留表单和页面状态。受 Electron 的窗口隔离限制，移入弹出窗口或返回主窗口时需要重建网页 guest：网页会在目标窗口重新加载，保留当前地址、前进后退历史、个人资料和缩放；未提交的表单、页面脚本等临时状态不保证保留。前进后退历史在每次导航后更新，仅用于本次运行中的窗口迁移及网页崩溃后的重试恢复，不写入磁盘。地址、标题、缩放和个人资料随本设备的智能体工作区保存。关闭 Browser 模块会释放网页 guest；重新启用可恢复已保存标签。关闭 Agent 只释放终端运行资源，不关闭 Browser 页面。

## 个人资料与 Cookie

“默认”个人资料始终存在，不能删除。设置页或更多菜单可创建个人资料，名称为 1～40 个字符。每份个人资料隔离 Cookie、localStorage 和缓存；切换资料会先确认，再重新加载当前网页。删除资料会确认受影响的标签、关闭它们并清理网站数据，已下载文件保留。

只有打开导入菜单时才扫描本机浏览器。支持检测 Chrome、Chromium、Edge、Brave、Firefox，以及有相应平台安装目录的 Arc、Comet、Helium。读取前复制 SQLite 数据库及 WAL/SHM 到库内临时目录，使用终端辅助程序只读读取，用后清理。macOS 可能请求钥匙串授权；Linux v11 需要可用的钥匙环；Windows 上 Chromium 系浏览器的 Cookie 带应用绑定加密（v20），只有浏览器自己能解：HUHU 会把源资料的 `Network/Cookies`（含 WAL）和 `Local State` 只读复制到临时 user-data-dir，用该浏览器自己的可执行文件以 `--headless=new --remote-debugging-pipe` 打开副本，经 DevTools `Storage.getCookies` 取得明文后立即关闭进程并删除副本；找不到浏览器、启动失败或超时时回退到直接读取 SQLite，并在结果里说明原因与下一步。源浏览器正在运行并锁定 Cookie 数据库时，先做有界重试和稳定快照，再尝试共享句柄读取（无需管理员权限）；仍被锁则提示完全退出浏览器后点“重试”，不会把原始 errno 抛给用户。Google Cookie 会被有意排除（搬运登录会被判为会话盗用并使源浏览器掉线），结果提示按原因分行并给出下一步，数量为 0 的项不显示。真实浏览器自测见 `cdp.e2e.test.ts` 顶部说明。系统密钥桥的输入走 stdin；最终 `security` / `secret-tool` CLI 仅经 argv 接收非机密的 service/account/application 查询元数据，密码从 stdout 返回，Cookie 密文和密钥不放入 argv。详见[Cookie 导入隐私](privacy.md#cookie-导入)。

也可导入 Netscape `cookies.txt` 或 Cookie-Editor／EditThisCookie 的 JSON 数组。只替换成功验证的精确导入域名（忽略域名前的点）；未列入导入的父域、子域及其他域名保持原状；Google 及其子域不会导入，请在 HUHU 中直接登录。完全无法写入时保留原 Cookie。成功后可“全部刷新”当前资料的标签，使登录状态生效。

Cookie、缓存和站点数据位于 `.huhu/browser/<device-id>/profiles/<id>/session/`；下载文件位于同资料的 `downloads/`。资料元数据在 `profiles.json`，最近 500 条历史及按“个人资料 + 来源”保存的权限在 `state.json`。敏感权限默认拒绝，可在站点菜单中授权；网站请求时可用提示条允许或拒绝。

下载栏显示进行中的下载和最近十分钟的完成记录，可取消、重试、打开文件、显示所在文件夹或清除记录。关闭有下载进行中的标签需要确认。

## 链接与智能体材料

设置页可选择终端链接默认在 HUHU 或系统浏览器打开；普通点击可显示操作菜单，Ctrl/Cmd 点击直接使用默认目标，Shift+Ctrl/Cmd 点击可反向打开。开启“接管笔记中的外部链接”后，阅读视图外链遵循同一目标；默认关闭。HUHU 已有相同地址的标签时直接切换。

抓取模式会高亮元素，点击后显示锚定预览：截图、文字、选择器、HTML 摘要、计算样式，以及页面明确提供的源码位置。可复制内容或附加到正在运行的智能体，当前组的会话优先。标注模式支持连续选择、编辑、删除与批量附加；截图绘制提供画笔、高亮、箭头、矩形、椭圆、文字、撤销、重做和清空。

图片保存在 `.huhu/browser/<device-id>/artifacts/`。材料以括号粘贴进入智能体输入区并切换到目标标签，**不会自动回车**，且只粘贴一次；目标会话已失效、忙碌或 10 秒内输入未就绪时准确报错，不重放。目标是一个已有会话（其所属 Space 由会话决定），浏览器不会为此新建会话。网页内容是参考材料，不构成新的操作授权。

## 本地数据与支持范围

Session 始终使用库内显式目录，不回退到 Obsidian 全局会话。支持点目录的文件同步可以备份 `.huhu/`，Obsidian Sync 不包含它；Cookie 和登录状态不能保证跨设备可用。建议把 `.huhu/browser/` 加入 Git 忽略，防止登录数据与截图随源码提交。

旧会话迁移仍使用库内 Session 的冷重启与恢复副本机制；遇到来源归属不明、路径逃逸、链接或来源变化时停止该分支。默认浏览器身份清理 Electron／Obsidian 标识，并对 Google 登录页使用兼容 UA；更改身份设置需要重启后生效。

部分登录服务、DRM 和依赖浏览器扩展的网站仍可能限制嵌入式浏览器，可用系统浏览器打开。超大网页无法整页截图时，可改用可见区域截图。Windows 和 macOS 的 Cookie 密钥读取与 Windows 的浏览器自解密路径需要对应系统实测（Linux 已用真实 Chrome 端到端验证 DevTools 管道路径）；Linux 的本地 Chrome/Cookie 夹具可验证读取与隔离流程，不代表真实账号登录或所有钥匙环后端都已验证。界面与算法来源见 [Orca 来源与适配范围](third-party/orca-terminal-workbench.md)。
