# 批注

批注使用 Obsidian 右侧栏与笔记旁的浮窗，不再提供独立工作台页面。行级和选区批注保存在当前库的 `.huhu/editor/comments/`，不会改动笔记正文；源码和实时预览可创建，阅读模式可查看已有批注。

## 添加与查看

首次启用批注模块并完成布局加载后，右侧栏会出现「批注」图标（对话气泡）。点击查看本笔记的批注；可切换到全库、按解决状态筛选，或按文中位置、创建时间、最近活动排序。全库按笔记折叠分组，展开时才加载正文；点击线程可跳转原文，更多菜单提供定位和线程操作。保留的已删除笔记批注归入「找不到的笔记」。

关闭侧栏标签后不会自动重开。用命令「打开批注面板」重新打开；设置可选择左侧栏。

- 鼠标靠近行首左侧，点击出现的添加图标，写一条行级批注。
- 选中文字后点击「批注」，或运行「为选区添加批注」。没有选区时对当前行添加。
- 编辑框贴在文字旁边。Ctrl/Cmd+Enter 提交，Enter 换行，Esc 取消。输入法组字期间不会提交。
- 前置元数据和围栏代码块不提供添加入口。
- 有批注的行显示气泡，多条批注显示数量；选区批注显示文字高亮。

在高亮文字或行图标上停留 350 毫秒会显示线程浮窗；移开 300 毫秒关闭。移入浮窗或正在编辑、回复时保持打开。点击标记或使用「显示光标处批注」可固定浮窗。Esc 先取消编辑，再关闭浮窗；关闭恢复编辑器原位置。手机使用底部抽屉。

阅读模式可以点击已有批注的高亮或行图标查看线程，不显示添加入口。弹出窗口中的浮窗留在笔记所在窗口。

## 线程操作

面板和浮窗都支持 Markdown 正文、回复、原地编辑、解决或重新打开、删除、跳转原文。只有作者名为空或与当前作者名相同的消息可以编辑。删除整条线程需要确认；删除回复后可在 5 秒内撤销。

已解决线程默认折叠。原文删除或无法匹配后显示「已脱离」；点击「重新挂上」，在相应笔记选中新位置，再回面板确认。脱离后不会自动猜测新的位置。

笔记内容变化时，批注先检查缓存，再按原文、前后各 50 字上下文及附近 200 行的模糊匹配定位。实时编辑会移动锚点；文件移动或重命名会更新旁路路径。默认删除笔记时一起删除批注，也可以设置为保留。

## 设置与命令

设置 → 编辑器提供作者名、gutter 图标及数量、行高亮、选区按钮、已解决高亮、主题强调色或自定义颜色、悬停延迟、模糊容差、删除策略、面板位置及默认排序。

命令包括：为选区添加批注、打开批注面板、显示光标处批注、下一条批注、上一条批注、解决本笔记全部批注（需确认）。未设置默认快捷键。

## 存储与恢复

v2 文件由 `index.json`、`pending.json` 和 `files/<路径 SHA-256 前 16 位>.json` 组成，记录线程类型、锚点、作者、消息、创建及编辑时间。写操作串行执行，恢复日志在文件、索引和清理全部完成后才移除。

写盘失败会保留草稿并提供重试；重试不会重复创建已接受的批注。关闭模块会封存存储并完成已接受的写入，再允许新实例读取。

旧版 v1 数据不迁移、不读取、不覆盖。面板会提示发现旧版数据；请先将整个旧 `.huhu/editor/comments/` 目录另存，再创建 v2 批注。损坏文件保留在 `set-aside/`，本次会话会报告错误；恢复原文件或保留备份后重新启用模块。

关闭模块会清除编辑器集成、阅读标记和每窗口浮窗，侧栏保留开启模块的提示。
