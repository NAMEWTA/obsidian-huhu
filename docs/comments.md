# 高亮摘录与批注

HUHU 将原来的「批注」扩展为 **以选区高亮为主、以摘录卡片为管理中心** 的 Markdown 阅读标注功能。你可以先高亮、以后再记笔记；原有行级批注、回复、解决与重挂依然存在。数据存于 `.huhu/editor/comments/`，**不会修改原 Markdown 正文**。

## 划词高亮

在 Markdown 编辑器中选中文字后，浮动工具条会提供黄色、粉色、蓝色、绿色与设置中建立的自定义颜色。点颜色立即创建或更新高亮，无需先写评论。点「添加笔记」则先建立默认黄色高亮并进入笔记编辑；关闭笔记不删除已建立的高亮。也可以使用命令「为选区添加高亮」。同一精确选区再次标注会更新原卡片颜色，交叠或嵌套选区允许各自独立卡片。

高亮文本在编辑器、实时预览和阅读模式中呈现相应颜色，点击或悬停会打开关联卡片；交叠处保留多个卡片 ID，浮窗可以浏览各自笔记。阅读模式仍只查看/管理已有高亮，不新增划词入口。前置元数据和代码块不提供高亮创建；复杂或无法可靠映射的选择不得静默错标。

原有在行首 gutter 上添加批注、无选区时对当前行留言、讨论消息与回复的流程继续兼容。旧行级批注不会变成虚假的选区高亮。编辑器选择浮层默认是高亮工具条，原批注仍可用既有命令和 gutter 添加。

## 高亮侧栏

原右侧栏批注面板演进成高亮面板，保留原视图 ID `huhu-comments-view`，并支持左/右侧栏位置设置。当前笔记/全库切换，搜索摘录、自由笔记、标签、讨论或来源路径；按颜色过滤；按文件、颜色、标签分组；按文中字符位置、创建时间或最近活动排序。

每条摘录卡片展示原文、颜色、来源、笔记/讨论、标签；可以改颜色、直接编写 Markdown 笔记、管理标签、置顶、归档、删除或回到原文。归档不会从正文撤销高亮，侧栏可切换显示归档项。

批量管理模式支持勾选、选中当前可见项、统一换色、添加标签、归档或确认删除。遇到部分失败时，已成功项保留、失败项继续被选中，可重新操作。导出操作将可见条目或选中项另存为 Markdown，包含摘录、颜色、标签、位置、笔记与讨论。默认目录在 `huhu/导出/高亮/`，可在设置中调整；导出文件不会覆盖原笔记。

全库普通浏览仍按文件折叠并按需加载正文。全库搜索、颜色和标签分组需要读取被索引的 sidecar，以便检索所有条目。找不到原始笔记的条目保留在列表中；定位失败不使用行号猜测别处。

## 讨论、锚点与旧数据

旧批注的 Markdown 消息、作者、回复、原地编辑、解决/重开、删除、移动文件后的路径修复、原文删除后的「已脱离」及明确「重新挂上」均保留。讨论状态与颜色、归档状态分开，纯高亮可以完全没有讨论消息。

定位依赖原文、哈希、前后文和位置提示，编辑时跟随文本移动。无法匹配时以「已脱离」提示用户重新选择位置，不能悄悄转移到另一段相同文字。

旁路存储为 v3：`index.json`、`pending.json` 与 `files/<路径哈希>.json`。打开已有 v2 数据时先写入并验证 `.huhu/editor/comments-backups/` 备份，再升级索引和 sidecar；索引和文件提交通过可重放的 pending 写入记录恢复。旧 v1 数据依然不会被自动迁移或覆盖；损坏文件保留在 `set-aside/`，必须在备份后人工恢复。

设置 → 编辑器可配置作者名、面板位置、悬停、选区浮层、删除策略、颜色和自定义颜色/高亮导出路径。自定义颜色删除后已有高亮保留存储时的颜色快照，但不能再选择该颜色新建。

不支持由此模块直接标注 PDF/EPUB；HiLighter 的 AI、复习与脑图也未纳入本次 Markdown 核心。详细设计及测试边界见 [高亮实施计划](highlights-implementation.md)。
