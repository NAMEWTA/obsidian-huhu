# 图标

图标模块可以为文件、文件夹、标签页、书签、标签、属性以及部分界面入口设置图标和颜色，也可以用规则批量应用。模块默认开启，需要 Obsidian 1.13.0 或更高版本。图标设置统一在 **设置 → 图标**，也可执行 `HUHU: 打开图标设置`。主图标栏不再单列图标配置，旧链接会转到相应设置标签。

## 开始使用

1. 在 **设置 → 常规 → 功能模块** 中确认“图标”已开启。
2. 打开一篇笔记，在命令面板执行 `HUHU: 更改当前文件的图标`。
3. 在选择器中搜索图标，例如 `star` 或 `folder`，点击搜索结果即可应用并关闭选择器。底部按钮可在图标和表情符号搜索之间切换。
4. 需要调整颜色时，使用搜索框旁的颜色控件。只改颜色时，点击“保存”。

也可以在受支持项目的右键菜单中更改图标（“更改图标…”“删除图标”“重置颜色”）。桌面端默认点击图标即可打开选择器，这个行为由“可点击的图标”设置决定。

界面文案跟随 HUHU 的语言设置。图标名称和搜索关键词来自上游的英文资源，用英文关键词搜索通常更直接。

## 用规则批量设置

在 **设置 → 图标 → 常规** 用 **规则书 → 管理** 打开规则书，或执行 `HUHU: 打开规则书`。文件规则和文件夹规则分别管理。

例如，为所有 Markdown 文件统一设置图标：

1. 在文件规则中添加规则，填写便于识别的名称。
2. 添加条件：*扩展名* *是* `md`。
3. 选择图标和颜色，启用规则并保存。

条件可以使用名称、文件名、扩展名、文件夹树、路径、标题、链接、嵌入链接、标签、属性、创建和修改时间以及系统时钟。有多个条件时，可以选择“全部”“任意”或“无”满足。多条已启用的规则匹配同一项目时，按规则列表的顺序采用第一条命中的规则；规则可以移到顶部、移到底部，或拖动调整顺序。

如果手动更改图标后的显示与预期不同，先在规则书里检查是否有命中的规则。选择器会提示影响当前项目的规则。规则和图标数据一起保存，不会写进笔记正文。

## 默认文件类型图标

没有自定义图标、也没有规则命中的文件和文件夹，会按类型显示一组默认图标，这样文件列表里不会出现一排没有图标的条目。设置 **显示默认文件类型图标**（默认开启）控制它；关闭后，文件列表恢复为原来的做法：只给自定义过的项目和“显示所有文件图标”“显示所有文件夹图标”打开的项目显示图标。

默认图标和颜色由同一张表决定，Obsidian 的文件列表、笔记导航器（文件夹树和笔记列表）以及从 **设置 → 常规 → HUHU 文件** 打开的内容树都使用它。颜色取 Obsidian 主题的颜色变量，跟随亮暗模式和主题。

| 类型 | 图标 | 颜色 |
|---|---|---|
| `.md` | 文档 | 默认文字色 |
| `.pdf` | 文档 | 红 |
| `.doc` `.docx` | 文字文档 | 蓝 |
| `.ppt` `.pptx` | 演示文稿 | 橙 |
| `.xls` `.xlsx` `.csv` | 电子表格 | 绿 |
| `.canvas` | 看板 | 紫 |
| `.base` | 数据库 | 青 |
| 图片 | 图片文件 | 粉 |
| 音频 | 音频文件 | 黄 |
| 视频 | 视频文件 | 紫 |
| `.zip` `.rar` `.7z` `.tar` `.gz` | 压缩包 | 默认文字色 |
| 代码（`.js` `.ts` `.py` `.rs` `.go` `.java` `.sh` 等） | 代码文件 | 青 |
| `.json` | JSON 文件 | 黄 |
| `.yaml` `.toml` `.xml` | 大括号文件 | 黄 |
| `.txt` `.log` 和其他类型 | 普通文件 | 默认文字色 |
| 文件夹 | 关闭的文件夹 / 打开的文件夹 | 默认文字色 |

几类固定名称的文件夹有专属图标，打开和关闭时不变：

| 文件夹 | 图标 |
|---|---|
| 库根目录下的 `日志`（默认位置 `huhu/日志`），以及其中的 `日记`、`周记`、`月记`、`季记`、`年记` | 日历系图标（绿） |
| `档案`（默认位置 `huhu/档案`） | 联系人图标（蓝） |
| `档案/个人档案`（含 `huhu/` 下的同名位置） | 个人图标（蓝） |
| `档案/企业档案`（含 `huhu/` 下的同名位置） | 企业图标（橙） |
| 名为 `attachments` 或 `附件` 的文件夹 | 回形针 |
| 名为 `templates` 或 `模板` 的文件夹 | 模板图标（紫） |

在笔记导航器里给文件夹或文件设置图标和颜色，会同时出现在 Obsidian 文件列表里，因为二者读取同一份图标数据；你的选择始终优先于默认图标。只设置颜色时，默认图标会换成你选的颜色。关闭图标模块后，导航器和 HUHU 文件树仍使用这张默认表。

## 按一级文件夹着色

设置 **按一级文件夹着色**（默认开启，需要同时开启“显示默认文件类型图标”）让文件夹更容易区分：库根目录下的每个一级文件夹，按名称的自然排序依次取调色板里的一种颜色，该文件夹里的所有子文件夹（任意深度）和它保持同一种颜色。调色板是 Obsidian 主题的八种颜色变量（蓝、橙、绿、紫、红、青、黄、粉），超过八个一级文件夹时循环使用，亮暗模式和主题都跟随。

- Obsidian 文件列表和笔记导航器的文件夹树使用同一个结果。文件图标仍按文件类型着色，不受影响。
- 你手动给某个文件夹设的颜色（或规则书里命中的颜色）优先，不被覆盖；它下面的其他子文件夹仍然沿用一级文件夹的颜色。
- 颜色按排序位置分配，所以新增、删除或重命名一级文件夹后，排在它后面的文件夹颜色会跟着重新分配，界面会自动刷新。
- 一级文件夹的颜色盖过固定名称文件夹（如 `日志`、`档案`）的默认颜色；它们的专属图标不变。关闭设置后恢复默认表里的颜色。

文件夹的默认图标放在展开箭头旁边，不会取代箭头；“极简文件夹图标”只影响你自己设置过图标的文件夹。

大部分设置都有对应的切换命令：切换更大图标、切换可点击图标、切换所有文件图标、切换所有文件夹图标、切换极简文件夹图标、切换 Markdown 标签图标、切换标题图标、切换标签胶囊图标、切换菜单操作、切换建议图标、切换快速切换器图标、切换「将文件移动」图标。

## 数据备份与关闭模块

图标数据保存在库内的 `.huhu/icons/iconic.json`，备份保存在同一目录。

| 文件 | 内容 |
|---|---|
| `.huhu/config/settings.json` | HUHU 的主设置；图标领域只在其中保存模块开关 |
| `iconic.json` | 图标与颜色、文件和文件夹规则、图标偏好、选择器状态 |
| `iconic.json.backup1`、`.backup2` 等 | 图标数据的自动备份；编号越小越新 |

保存时会合并约 300 毫秒内的连续修改。自动备份默认保留 2 份（可设为 0 到 9 份）；保存时若距上一份备份已满 3 小时，才会轮换出新的备份。这不是每次修改都产生一个历史版本。

主文件缺失、无法解析或为空对象，且存在第一份备份时，HUHU 会恢复 `.backup1` 并给出提示。它只使用 `.backup1`，不会去找后面的备份。需要手动恢复时：先关闭图标模块，另存当前的主文件和备份，把确认有效的备份复制为 `iconic.json`，再重新开启模块。

关闭图标模块会撤下界面上的图标修改（包括编辑器和阅读视图），关闭相关弹窗，并把它的命令从命令面板中移除；已保存的数据会保留。图标搜索用的关键词和表情数据在第一次打开选择器时才加载（按图标名称匹配的规则，会在模块开启后于后台加载）。模块开启期间，对 `iconic.json` 的外部修改会通过文件监听和窗口重新聚焦检查被重新读取。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 图标栏上没有“图标” | 在 **设置 → 常规 → 功能模块** 中开启图标；关闭的功能不显示入口 |
| 找不到“更改当前文件的图标”命令 | 确认模块已开启，并先打开一个文件 |
| 用中文描述搜不到图标 | 尝试英文名称或关键词，并检查图标/表情符号搜索模式 |
| 新图标被规则覆盖 | 检查规则书、命中条件和规则顺序 |
| 删除自定义图标后仍显示图标 | 检查匹配的规则和“显示所有文件/文件夹图标”设置 |
| 同时装有独立的 Iconic 插件 | 使用 HUHU 的图标模块时请停用它，避免两者修改同一处界面；HUHU 不会导入它的数据 |

实机运行只覆盖 Linux 上的 Obsidian 桌面端；声明的最低版本不等于已在该版本上完成实机运行。
