# 笔记导航器

笔记导航器是 Obsidian 左侧栏里的双栏笔记浏览器：上面（或左边）是文件夹和标签，另一栏是所选文件夹或标签里的笔记，带预览文字、缩略图、日期和标签。它是第三种 HUHU 视图，与工作台、批注面板并列。行为参照 [Notebook Navigator](https://github.com/johansan/notebook-navigator)（GPL-3.0）的使用方式，HUHU 是独立重写，没有复制它的代码，见[第三方说明](third-party/notebook-navigator.md)。

## 打开

笔记导航器由 **设置 → 常规 → 功能模块** 里的“笔记”开关管理，工作台图标栏里没有它的条目：

- 开关打开（包括插件加载时已经打开）：布局就绪后，Obsidian 左侧栏里有一个“笔记”标签页（笔记本图标）。左侧栏已经有它就直接沿用，不会重复添加，也不会抢走焦点。
- 开关关闭：左侧栏里的所有导航器标签页随之消失；插件加载时开关已经关闭，上次布局里残留的标签页同样会被移除。
- 开关保持打开时手动关掉了这个标签页：本次运行期间不会被强行放回来，下次加载插件时会重新放到左侧栏。
- 停用或卸载整个插件不改动布局。

标签页被关掉后，仍可以用命令（没有默认快捷键，可在 Obsidian 快捷键里绑定）：

- 命令“打开笔记导航器”：展开左侧栏并把键盘焦点放到笔记列表；
- 命令“在导航器中定位当前笔记”。

## 导航栏

- 文件夹树按名称自然排序（`note 2` 在 `note 10` 之前）。展开和折叠状态按设备保存。
- 每个文件夹右侧的数字是**深度统计**：它自己和所有子文件夹（逐级下探到最底层）里的文件总数，库根目录行就是整个库的文件数。统计遵循导航器当前显示的文件类型（默认只数笔记、画布和 Base，开启“显示所有文件类型”后数全部文件）和隐藏规则。数字在导航器启动时一次算好，之后随创建、删除、重命名、移动文件按所在文件夹的祖先链增减，不在渲染时重新遍历；一万个文件的库首次统计在几十毫秒以内。设置“统计嵌套笔记”默认开启，关闭后只数文件夹直接包含的文件（标签同理：开启时包含子标签）。
- 标签树按 `#a/b/c` 的层级展示，计数是该标签下的笔记数；“无标签”行列出没有任何标签的笔记。
- 文件夹和标签的图标与颜色来自[图标](icons.md)模块的规则和单项设置；图标模块关闭时用默认图标。
- 设置可以显示库根目录、隐藏标签树、统计子文件夹和子标签中的笔记。
- 文件夹按一级文件夹顺序配色，见[图标](icons.md#按一级文件夹着色)。

## 笔记列表

每行显示标题、1–5 行预览、第一张图片的缩略图、日期和标签（点击标签打开该标签）。预览去掉前置元数据、代码块、注释、HTML 和 Markdown 标记。缩略图取前置属性（默认 `cover`、`image`、`thumbnail`）里的图片，其次是正文第一张本地图片；远程图片不会被下载。

- 排序：修改日期、创建日期、名称，升序或降序。
- 分组：按日期（今天、昨天、前 7 天、前 30 天、本年各月、更早的年份；只在按日期排序时生效）、按所在文件夹，或不分组。
- 置顶：右键笔记“置顶”。置顶按文件夹或标签分别保存，显示在列表最上方的“已置顶”区。
- 紧凑模式：每篇一行，不显示预览、缩略图和标签。
- “显示子文件夹笔记”开关：文件夹和标签同时列出下层的笔记。
- 列表是虚拟滚动，行高由设置决定，一万篇笔记的库也只渲染可见行。

## 布局

默认是上下两栏，拖动分隔条调整大小（大小按设备保存）。更多菜单可切换为左右并排，或单栏：单栏模式下导航栏和列表交替显示，切换带滑动动画；系统设置了“减少动态效果”时没有动画。

## 键盘

窗格获得焦点时可用（Obsidian 自己的全局快捷键如 F2 在这时让给导航器）。所有按键可在 **设置 → 笔记 → 键盘** 里改成逗号分隔的列表，修饰键写 `Mod`（macOS 的 Cmd，其他系统的 Ctrl）、`Ctrl`、`Alt`、`Shift`，例如 `j, Ctrl+n`。

| 按键 | 导航栏 | 列表 |
|---|---|---|
| ↑ / ↓ | 选上一个/下一个文件夹或标签 | 选上一篇/下一篇并（按设置）打开 |
| ← | 折叠，已折叠则转到上级 | 回到导航栏 |
| → | 展开，已展开则转到列表 | 打开并转到编辑器 |
| Tab / Shift+Tab | 转到列表 | 转到编辑器 / 回到导航栏 |
| F2（macOS 为 Enter） | 重命名文件夹 | 原地重命名笔记 |
| Enter（非 macOS） | 转到列表 | 打开并转到编辑器 |
| Delete / Backspace | 删除文件夹 | 删除所选笔记（遵守删除设置，先确认） |
| Home / End、PageUp / PageDown | 首项/末项、翻页 | 同左 |
| Shift+↑ / ↓、Shift+Home / End | — | 扩选、选到首篇或末篇 |
| Mod+A | — | 全选当前列表 |
| 右键菜单键 / Shift+F10 | 打开当前行的菜单 | 打开光标所在笔记的菜单 |

多选还可以用 Mod+点击（逐篇加减）和 Shift+点击（选一段）。列表的选中项始终是当前列表里看得见的笔记：搜索、隐藏规则或库的变化把某篇挤出列表时，它同时退出选择，删除、移动、复制、拖放也只作用于看得见的选中项。输入法组字期间所有按键都不触发。

## 文件操作

右键菜单（笔记）：在新标签页打开、在右侧打开、新建笔记、重命名、创建副本、移动到…、置顶/取消置顶、在默认应用中打开、在系统资源管理器中显示（macOS 为“在访达中显示”）、复制路径、删除。右键文件夹：新建笔记、新建文件夹、重命名、在系统资源管理器中显示、复制路径、删除。操作作用于所选的全部笔记；桌面端的系统项移动端不显示。

HUHU 自己的项之后、分隔线下面，会列出 Obsidian 自身与其他插件通过 `file-menu`（多选时 `files-menu`）事件加给文件列表的菜单项（新建白板/Base、书签、在新窗口打开、复制路径子菜单、更改图标等）。HUHU 已有的同类项（移动到…、默认应用、系统资源管理器）不重复；宿主的“复制路径”子菜单（Obsidian URL、库内路径、系统路径）取代 HUHU 单个“复制路径”项。

- 新建笔记放在当前文件夹；在标签里新建会把该标签写进前置属性。
- 重命名保留扩展名，名称含不允许的字符或已存在时留在编辑框里并提示。
- 删除按 Obsidian 的“已删除文件”设置处理（回收站或永久删除），删除后自动选中下一篇。
- 移动会更新链接，遵守 Obsidian 的“自动更新内部链接”设置。

拖放：把笔记（或多选）拖到导航栏的文件夹上移动；拖到标签上给它们加标签；拖到编辑器里插入 `[[链接]]`。拖着笔记悬停在折叠的文件夹上约 0.65 秒会自动展开。文件夹也可以拖到其他文件夹里。

## 打开笔记

- 在列表里**单击**笔记（或快捷方式、最近、文件夹笔记）会在**新标签页**打开；如果这篇笔记已经在某个标签页里打开，就切换到那个标签页，不会再开一个。双击或按 Enter / → 同样遵循这条规则，并把光标放进编辑器。
- 设置 **行为 → 点击笔记时打开于** 可以改成“当前标签页”（单击替换当前标签页）。点击时按住 **Alt** 得到相反的效果。Mod+点击、Shift+点击仍是多选，不打开。
- 用键盘上下键选择笔记并在“选中即打开”时自动打开，仍然显示在当前标签页里，不会每按一次键就新开一个标签页。
- 右键“在新标签页打开”总是新开标签页。

## 新建笔记

- 导航器里新建的笔记默认命名为 `YYYY-MM-DD-未命名`（英文界面为 `YYYY-MM-DD-Untitled`），日期是创建当天；同名时自动加序号（`… 2`）。用模板或自定义命令创建时，文件名格式仍由模板或命令决定。
- 原地重命名（F2）遇到 `YYYY-MM-DD-名称` 形式的文件名时，只选中“名称”部分，日期前缀保持不动；其他文件名整个选中。
- 没有适用模板的新笔记以一段默认属性开头，具体内容由你自己填写：

  ```yaml
  状态: 在用
  tags:
    -
    -
  ```

  在标签视图里新建时，标签写进第一个空的 `tags` 项。默认属性可以在 **设置 → 笔记 → 行为 → 新笔记的默认属性** 里编辑，清空表示不加属性。有模板时以模板为准。

## 粘贴和拖入附件

在 Markdown 笔记里粘贴或拖入图片、PDF 等文件时，HUHU 把它们保存到**这篇笔记所在文件夹下的 `assets` 文件夹**（不存在会自动创建），文件名为 `YYYY-MM-DD-HHMMSS-xxxx.扩展名`（`xxxx` 是四位随机十六进制，同一秒的多个文件也不会重名），然后在光标处（拖放时在落点）插入链接。链接格式遵循 Obsidian 的“使用 Wiki 链接”和“新链接格式”设置，图片、PDF、音视频以嵌入形式插入。

- 纯文字粘贴不受影响。从网页或表格复制得到的“文字加一张截图”按文字粘贴，交给 Obsidian 处理。
- 设置 **行为 → 附件保存在笔记同级目录**（默认开启）可以整体关掉，回到 Obsidian 自己的附件位置设置；**附件文件夹名称**（默认 `assets`）可以改成别的名字，只能是一层文件夹名。
- 画布等非 Markdown 编辑器不处理；个别文件保存失败时提示出错的文件名，其余文件照常保存并插入。

## 自动定位与历史

切换笔记时，导航器展开父文件夹并选中该笔记（设置“定位当前笔记”，默认开启；如果笔记已在当前列表里就不换文件夹）。“后退/前进”命令在你选过的文件夹和标签之间移动；“上一篇/下一篇”命令在当前列表里切换笔记。

## 命令

命令面板里带 `HUHU:` 前缀，没有默认快捷键：打开笔记导航器、在导航器中定位当前笔记、导航器：新建笔记 / 新建文件夹 / 移动所选笔记 / 删除所选笔记 / 切换单栏和双栏 / 切换分栏方向 / 切换显示子文件夹笔记 / 切换紧凑行 / 折叠全部 / 展开全部 / 打开下一篇 / 打开上一篇 / 后退 / 前进 / 重建缓存 / 搜索笔记 / 搜索整个库 / 显示或隐藏被隐藏的项目 / 添加或移除快捷方式 / 打开快捷方式 1–9 / 置顶全部文件夹笔记 / 将笔记转换为文件夹笔记 / 将当前笔记设为文件夹笔记 / 分离文件夹笔记 / 切换日历 / 打开今日、本周、本月、本季、本年笔记 / 打开下一期、上一期、上级周期笔记 / 用模板新建笔记 / 合并笔记 / 给所选笔记添加标签、移除标签、清空标签 / 撤销上一次标签修改 / 切换库配置档（及切换到配置档 1–3），另外每条自定义的“创建笔记”命令各有一条。

## 缓存与数据位置

预览文字和缩略图路径保存在浏览器的 IndexedDB 库 `huhu-navigator-<库 id>` 中，另有内存 LRU。每条记录记着生成时的文件修改时间和图片属性设置，只有文件改动或设置变化的那一部分会重新处理；首次打开时在 Obsidian 空闲时分批读取笔记，不阻塞界面，之后启动直接读缓存。它不在库目录里，不被同步，可随时用“重建缓存”命令或设置页的“重建”按钮丢弃，不影响笔记。笔记内容和预览不会离开本机。

设置保存在全局设置的 `navigator` 命名空间：显示、排序、置顶、快捷键、快捷方式、分区顺序、隐藏规则、文件夹笔记和按项覆盖的外观随库；布局方向、窗格大小、展开状态、选中项、搜索框内容、最近笔记、分区折叠状态、“显示隐藏项”开关保存在本设备设置。位置见[数据与恢复](data.md)。

## 搜索

列表栏标题上的搜索按钮（或命令“导航器：搜索笔记”）在列表上方打开过滤框，筛选范围是当前所选文件夹、标签或属性及其下层。关闭搜索框后过滤停止，输入的内容保留并按设备保存，重启后仍在；再次打开即恢复。

- 过滤框里：Enter 或 Tab 转到列表（没有选中项时选第一条结果），Shift+Tab 回到导航栏，Esc 关闭搜索并回到列表。星标按钮把当前查询存为快捷方式。
- “导航器：搜索整个库”选中库根目录并带着当前查询打开搜索。
- 按住 Mod 点击标签行、列表里的标签胶囊或属性行，会把它加进查询：默认 AND，Mod+Shift 为 OR，再点一次移除。手写的取反项（如 `-#a`）不会被移除。

### 语法

多个条件用空格分隔，全部满足才匹配，大小写不敏感。

| 写法 | 含义 |
|---|---|
| `word` | 显示名或别名包含 word；多个词各自满足即可（可分别落在名称或别名上） |
| `-word` | 显示名和别名都不含 word |
| `".F"` | 以双引号开头的项永远按字面文字匹配，不当作标签、属性、日期或过滤器；`-".F"` 为排除 |
| `#tag` | 带该标签，嵌套标签 `#tag/sub` 也算；`#` 为有任意标签，`-#` 为没有标签，`-#tag` 为不带该标签 |
| `#a #b`、`#a AND #b` | 两个标签都有 |
| `#a OR #b` | 任一标签；AND 优先于 OR，`#a OR #b AND #c` 即 `#a` 或（`#b` 且 `#c`） |
| `.key` | 有以 key 开头的属性键 |
| `.key=value` | 键名（不分大小写）恰好是 key，且它的值（列表属性的任一项）包含 value；`-.key`、`-.key=value` 为排除。只有不带值的 `.key` 按前缀匹配键名，所以 `.status=done` 不会命中 `status-old: done` |
| `."Reading Status"="In Progress"` | 含空白的键和值要用双引号 |
| `has:task` | 有未完成任务；`-has:task` 为没有 |
| `folder:meetings` | 所在路径中某一级文件夹名包含 meetings（含下层）；`-folder:` 为排除 |
| `folder:/work/meetings` | 恰好在该文件夹，不含子文件夹；`folder:/` 为库根目录 |
| `ext:md`（或 `ext:.md`） | 扩展名为 md；`-ext:pdf` 为排除 |
| `@today` `@yesterday` `@last7d` `@last30d` `@thisweek` `@thismonth` | 相对日期范围（周从周一算起） |
| `@2026-02-07`、`@20260207` | 某一天 |
| `@2026`、`@2026-02`、`@202602` | 某年、某月 |
| `@2026-W05`、`@2026W05` | ISO 周 |
| `@2026-Q2`、`@2026Q2` | 季度 |
| `@13/02/2026`、`@07022026` | 带分隔符或纯数字的日期；两部分都不超过 12 时按系统区域的日月顺序理解 |
| `@2026-02-01..2026-02-07` | 闭区间；`@2026-02-01..`、`@..2026-02` 为开区间 |
| `@c:…` / `@m:…` | 指定创建日期 / 修改日期；`-@…` 为排除 |

不带 `c:`/`m:` 的日期用哪个字段取决于列表的排序（按创建日期排序用创建日期，按修改日期用修改日期；按名称排序时用设置“按名称排序时的日期过滤”）。

AND 和 OR 只在查询只含标签和属性条件（`#tag`、`-#tag`、`#`、`-#`、`.key`、`.key=value` 及其取反）时才是运算符，必须大写；只要查询里还有名称、日期、`has:`、`folder:` 或 `ext:`，它们就当作文件名里的词。没写完的过滤器（如 `folder:`、`@`、无法识别的日期）不会让列表变空：空值被忽略，无法识别的日期按文字匹配。

## 快捷方式与最近笔记

导航栏最上面的“快捷方式”分区可以固定笔记、文件夹、标签、属性和保存的搜索：

- 添加：右键文件夹、标签、属性、笔记选“添加到快捷方式”，把文件夹、标签、属性或笔记拖到快捷方式行上，搜索框里点星标，或用命令“导航器：添加或移除快捷方式”（导航器有焦点时作用于所选项，否则作用于当前笔记）。
- 排序：拖动一行放到另一行的上半或下半，或在右键菜单里“上移/下移”。右键还可以重命名、移除。
- 键盘：方向键、Home/End 在导航栏的所有行之间移动（含分区标题、快捷方式、最近）；在快捷方式或最近行上，→ 或 Enter 打开，F2 重命名快捷方式，Delete 移除；“右键菜单”键（或 Shift+F10）打开当前行的菜单。
- 点击打开：笔记直接打开并在导航器里定位，文件夹/标签/属性切换到它，保存的搜索选中库根目录并应用查询。目标不存在时显示删除线。笔记或文件夹被重命名后快捷方式跟着改，被删除时移除。
- 命令“导航器：打开快捷方式 1”到“9”按导航栏里**显示出来**的顺序打开（被隐藏规则隐藏的快捷方式不占编号，拖动重排后编号随之改变）。指向已不存在或被隐藏的文件夹、标签、属性的快捷方式一律拒绝打开，无论从导航栏、命令还是看板进入。

“最近”分区列出最近打开的笔记（数量见设置，默认 5，最多 30），按设备保存，右键可移除或清空。被隐藏规则隐藏的笔记不出现在最近列表里（历史仍保留，开启“显示隐藏项”后重新出现并变淡），数量限制只数可见的笔记；指向被隐藏笔记或文件夹的快捷方式同样随隐藏规则隐藏。

## 属性浏览

“属性”分区按“属性键 → 值 → 笔记数”浏览前置属性。点击键列出带该属性的笔记，展开后点击某个值列出取该值的笔记（键、值不分大小写；列表属性的每一项各算一个值；一个键最多列出 300 个值）。设置里可以限定显示哪些键（逗号分隔），不填则列出除 `tags`、`aliases`、`cssclasses` 以外的全部键。按住 Mod 点击键或值，把 `.key` / `.key=value` 加进搜索。

## 按属性分组

设置“分组属性”里写上属性名（如 `status`），排序菜单的“分组”里就多出“属性：status”。值相同的笔记归到同一标题下，没有该属性的笔记放在最后的“无”组，组按值自然排序；列表属性（如 `[Books, History]`）合成一个组。

## 单独覆盖外观

右键文件夹、标签或属性，选“列表外观…”（或列表栏“更多”菜单），可以为这一项单独设置：排序字段、方向、分组、标题行数、预览行数、紧凑模式、是否包含子项。没有打开的选项跟随全局设置。排序/分组菜单和紧凑、子项开关修改的是当前项自己已覆盖的那些选项，其余仍改全局。文件夹重命名时覆盖设置跟着改，删除时一并清除。

## 隐藏规则

设置“隐藏项”里每行一条规则：

- 文件夹：文件夹名（任意位置），或以库根起算的路径（`/Archive/Old`）；`*` 匹配任意文字。文件夹里的内容一并隐藏。
- 标签：如 `draft`、`temp/*`；带这些标签（含嵌套标签）的笔记被隐藏。
- 文件：文件名（`*.excalidraw.md`）或路径（`/Templates/Daily.md`）。
- 属性：`key` 或 `key=value`，带匹配前置属性的笔记被隐藏。

隐藏只影响显示，索引始终保留全部内容。“显示隐藏项”开关（导航栏的眼睛按钮、更多菜单、命令“导航器：显示或隐藏被隐藏的项目”）会让它们以变淡的样式重新出现。右键文件夹、标签、笔记选“隐藏”会追加一条规则。

## 文件夹笔记

设置里开启“使用文件夹笔记”后，与所在文件夹同名的笔记（或设置了固定名称如 `index` 时，该名称的笔记）就是这个文件夹的笔记。

- 点击文件夹同时打开它的文件夹笔记（可在设置里关掉）。
- 文件夹（和标签、属性）行**单击**：选中，未展开则展开，已展开则只选中、不收起，方便接着点子文件夹；**双击**：切换收起/展开（已展开的收起，已收起的展开，双击的第一下不会先动它）；行首小箭头单击直接切换；键盘用 →/← 展开/收起。
- 右键笔记：“设为文件夹笔记”把它改名为所在文件夹的文件夹笔记名（已存在则提示，不覆盖）；“转换为文件夹笔记”新建与笔记同名的文件夹并把笔记移进去。右键有文件夹笔记的文件夹：“分离文件夹笔记”输入新名称后改名。
- 命令：导航器：将笔记转换为文件夹笔记 / 将当前笔记设为文件夹笔记 / 分离所选文件夹的文件夹笔记 / 置顶全部文件夹笔记（把每个文件夹的文件夹笔记置顶在该文件夹里）。

## 分区的折叠与重排

导航栏根上的五个分区（快捷方式、最近、文件夹、标签、属性）各有标题行：点击折叠/展开（折叠状态按设备保存），拖动标题行或右键“上移/下移”调整顺序（顺序随库保存）。没有内容的分区不显示。键盘同样可以操作：方向键移到分区标题，→（或 Enter）展开，←折叠，在分区内的行上按 ← 回到所属标题；命令“展开全部”会同时展开被折叠的分区。

## 日历与周期笔记

导航栏右上角的日历按钮（命令“导航器：切换日历”）展开日历，是否展开按设备保存。日期的主动作与看板相同：选择日期后在弹窗查看和编辑当天待办，侧栏不展开日程列表。查看、翻月、返回今天都不会创建笔记。

- 年月标题打开十二个月的年份面板；左右箭头及日格聚焦时的 PageUp/PageDown 按当前显示范围翻页；紧凑窗口按显示周数前后移动，完整月份按月移动。可选完整月份（4～6 周），或 1～5 周的紧凑窗口，默认仍是完整月份。周起始日、周号、周期归属沿用有效的导航器设置。
- 今天是填充圆标，选中日期是选中边框，当前周期笔记对应的日期或范围用虚线提示；相邻月、周末、键盘焦点分别显示。日期下的小矩形表示已有日记，小圆点表示尚有未完成待办，勾号表示当天任务全部完成，语义与看板一致。
- 日期右键菜单和日程栏的“日期和笔记操作”提供明确的打开、创建、新标签页、分栏动作。日历底部只保留日记入口；既有周记、月记等笔记、命令和模板设置保持可用。Mod+点击或中键仅打开已存在日记的新标签页；没有日记时仍选择日程。双击没有额外创建行为。
- 桌面悬停只预览所指日期的待办，最多六条并显示其余条数。离开、点击、Escape、滚动、缩放或切换日期时收起，过期请求不覆盖当前日期。键盘和触屏通过点击后的弹窗查看和编辑。
- 可选“显示首图”使用现有预览缓存：日期格使用淡化封面，大尺寸看板可使用选中日记的图片。无图或失败时保留正常日期和操作，不额外下载远程图片。
- 日程的任务来自看板日历已有的日期规则和来源范围，聚合 HUHU 管理的任务与已登记看板中的任务，不限于当天日记正文，也不会收集普通手写复选框。任务时间与提醒独立，提醒不另建一个日历日期。筛选、排序、勾选、删除、来源打开与提醒在各入口保持一致；每个入口独立保留浏览日期。

### 固定的日志目录

周期笔记不会散落在库里：它们保存在库内一个固定可见的“日志”档案目录（默认 `huhu/日志/`，可在 **设置 → 笔记 → 日历与周期笔记 → 日志文件夹** 改成别的库内路径），其下的结构固定，不能逐个周期自定义文件夹或文件名格式：

| 周期 | 路径 |
|---|---|
| 日记 | `huhu/日志/日记/YYYY/MM/YYYY-MM-DD.md`，如 `huhu/日志/日记/2026/10/2026-10-17.md` |
| 周记 | `huhu/日志/周记/gggg/gggg-Www.md`，如 `huhu/日志/周记/2026/2026-W42.md` |
| 月记 | `huhu/日志/月记/YYYY/YYYY-MM.md` |
| 季记 | `huhu/日志/季记/YYYY/YYYY-Qq.md` |
| 年记 | `huhu/日志/年记/YYYY.md` |

- 文件夹名称（日记、周记、月记、季记、年记）固定为中文，不随界面语言变化，这是你库里的目录结构而不是界面文字。创建时自动建好年份、月份等各级文件夹。
- 日志文件夹必须是库内相对路径：为空、含以 `.` 开头的一段（如 `.huhu`、`..`）或含 `\ : * ? " < > |` 时回退到默认的 `huhu/日志`。
- 周记按“周年”归档：周一开始时是 ISO 8601 周（2026-12-31 属于 `2026-W53`，2024-12-30 属于 `2025-W01`）；每周第一天是周日或周六时，包含 1 月 1 日的那一周是下一年的第 1 周（周日开始时 2026-12-31 属于 `2027-W01`）。文件夹里的年份就是这个周年。
- 每个周期（日、周、月、季、年）在 **设置 → 笔记 → 日历与周期笔记** 里只有两项：是否启用、模板。默认启用日记、周记、月记，季记和年记默认关闭。
- **只有精确的路径才算那一天的笔记**：`2026-10-15 旅行.md` 不会被当成 10 月 15 日的日记，也不会按前缀、通配或元数据去猜。放在旧位置（比如日记核心插件的文件夹，或旧版 HUHU 设置的文件夹）的笔记不会被移动，也不再被当作周期笔记；需要的话请自己把它们移进日志目录。
- 不再读取 Obsidian 的“日记”核心插件的文件夹、格式和模板；旧版的“日记来源”“文件夹”“文件名格式”设置已被丢弃，周期设置按新结构从默认值开始。
- “每周第一天”默认跟随 Obsidian 的语言，也可以固定为周一、周日或周六，同时决定周数和周记所属的年份。

命令“打开今日/本周/本月/本季/本年笔记”按当前日期打开（不存在则创建）。“打开下一期/上一期周期笔记”从当前打开的周期笔记算起（今天的日记 → 明天的日记，本周的周记 → 下周的周记）；“打开上级周期笔记”从日记到周记、从周记到月记、再到季记和年记，跳过没有启用的周期；跨月的一周属于它第一天所在的月。当前笔记不是周期笔记时给出提示。

看板与导航器日历共用任务写入服务。默认落点是所选日的日记，使用这里配置的日志目录和模板；也可选择看板日历设置中的固定文件、每天一篇或每任务一篇。笔记导航器关闭或日记周期停用时，默认日记写入和相关周期动作显示不可用，不回退到另一目录或空白模板。已有任务仍可查看、编辑；有效且未被任务来源排除的自定义落点继续可用。

从日历或自动化新增时，日期、待办时间和提醒由相应控件决定。标题里若含有扫描器会识别的日期字段（`due/start/end/scheduled/completion` 的日期内联字段、附带日期的 📅/🛫/🛬/⏳/✅ 标记或行尾 ⏰ 提醒），会明确提示输入无效，不改写标题、不创建文件。普通日期时间文字、未构成日期字段的文字和 Markdown 链接可以保留。来源笔记中已有的日期协议继续按原规则读取。

## 模板

模板是模板文件夹里的 Markdown 笔记（设置 **模板 → 模板文件夹**；留空则所有笔记都可选）。导航器创建周期笔记、用模板新建的笔记、自定义“创建笔记”命令的笔记，以及有文件夹模板的文件夹里的新笔记时套用模板。内置引擎在创建时替换下面的标记，**未知的 `{{…}}` 原样保留**，所以别的插件的模板照常能用；写 `{{!date}}` 可以保留 `{{date}}` 这几个字。

| 标记 | 结果 |
|---|---|
| `{{title}}` | 笔记的文件名（不含扩展名） |
| `{{folder}}` | 所在文件夹的名称 |
| `{{path}}` | 笔记在库里的路径 |
| `{{date}}` | 笔记的日期：周期笔记用它所在周期的第一天，并按它的文件名（日记 `YYYY-MM-DD`、周记 `gggg-[W]ww`、月记 `YYYY-MM`、季记 `YYYY-[Q]Q`、年记 `YYYY`）输出；其他笔记用今天，按设置里的日期格式 |
| `{{date:FORMAT}}` | 同上，按 Moment 格式输出，如 `{{date:dddd, MMMM D}}` |
| `{{date+1d}}`、`{{date-2w:FORMAT}}` | 加减偏移，单位 `y` 年、`Q` 季、`M` 月、`w` 周、`d` 日、`h` 时、`m` 分、`s` 秒 |
| `{{yesterday}}`、`{{tomorrow}}` | 笔记日期的前一天、后一天（可带格式） |
| `{{monday}}` … `{{sunday}}` | 笔记日期所在那一周的各天（可带格式），默认用设置里的日期格式（不是周记的文件名）；周记则是从笔记日期起的七天 |
| `{{time}}`、`{{time:FORMAT}}` | 现在的时间，默认格式见设置“模板里的时间格式” |
| `{{today}}`、`{{today:FORMAT}}` | 今天的日期，默认用设置“模板里的日期格式”；写入属性请用 `{{today:YYYY-MM-DD}}` |
| `{{now}}`、`{{now:FORMAT}}` | 现在的 ISO 8601 时间戳，默认 `YYYY-MM-DD[T]HH:mm:ssZ` |
| `{{cursor}}` | 从笔记里删掉，创建后光标放在这里 |
| `{{prompt:标签}}`、`{{value:标签}}` | 创建时询问一个值并填入；同一标签（包括文件名格式里的）只问一次；省略标签时叫 `Value` |
| `{{number}}`、`{{number:00}}` | “创建笔记”命令文件名里的序号（见下）；`{{number:00}}` 用 0 补到格式的长度。只在这样创建的笔记里有值，其他地方原样保留 |

前置属性里被引号包住的值（如 `title: "{{prompt:Title}}"`，包括引号跨多行的值、列表项和流式序列）会按 YAML 引号风格转义引号和反斜杠：双引号里 `"` 和 `\` 加反斜杠，单引号里 `'` 写成 `''`；判断时按 YAML 的结构（值的起点、锚点/类型标签、注释、块标量 `|`/`>`、普通标量里的引号）而不是只看前一个字符。**生成之后还会用 Obsidian 的 YAML 解析器校验**：把模板里 frontmatter 的每个替换值换成占位标记解析一遍得到“模板本意”，再解析真正生成的 frontmatter，二者结构必须一致、每个值必须读回成写进去的文字（未加引号的值允许被读成数字/布尔/空）。校验失败（YAML 被破坏，或含义与模板不同，比如未加引号的值里有 `: `、开头的引号、`#` 注释）时**不创建笔记**，并提示“用这些值填充‘模板名’会生成无效/含义不同的前置属性”。宁可报错，也不写出损坏或语义错误的 frontmatter。**生成的 frontmatter 必须始终能被解析**，并且探针树和实际树都必须通过同一个白名单；frontmatter 必须由模板自己写的开头 `---` 开始、并在模板自己的结束 `---` 处结束（替换值生成或移动围栏会被拒绝，因为那里的替换无法追踪）；只有模板 frontmatter 里一个占位符都没有时才跳过语义比较（含 `!!set`、`!!omap`、日期根的 frontmatter 一律无法校验）；任何一步无法证明“每个替换值读回等于写入的文字”时一律拒绝创建：用来比较的占位版本本身无法解析（例如别名的名字来自替换值）、或替换值出现在锚点（`&名`）、别名（`*名`）、类型标签（`!标签`）、键名里，都会拒绝，并提示“无法用这些值校验”。

**模板引擎**（设置里选）：

| 引擎 | 行为 |
|---|---|
| 自动 | Templater 已安装并启用，且模板里有 `<%` 时整篇交给 Templater，其余用内置引擎 |
| 内置 | 始终用内置引擎，`<% … %>` 原样保留 |
| Templater | 始终交给 Templater |

没有安装或启用 Templater 时一律降级为内置引擎（设置页会提示）。交给 Templater 的模板整篇由它处理，里面的 `{{…}}` 不再替换，自定义命令也不会为这类模板的正文询问 `{{prompt}}`（文件名格式里的仍会问）。Templater 创建笔记后，如果模板用了 `tp.file.cursor`，HUHU 在笔记打开后执行 Templater 的“跳到下一个光标位置”命令。Templater 自己的“新建文件时触发”选项独立于这里：它开着时会再处理导航器创建的每篇笔记，需要的话在 Templater 里关掉或排除相应文件夹。

### 文件夹模板

在某个文件夹里新建的笔记使用**最近的**设有模板的文件夹的模板，库根目录的模板就是整个库的默认模板，`Personal/DailyNotes` 上的模板在那里覆盖它。右键文件夹（含库根目录）选“设置文件夹模板…”挑选模板，并可勾选“仅此文件夹”（不含子文件夹）；选“不使用模板”移除。设置页“文件夹模板”里列出全部，可以逐条改模板、改成仅此文件夹或移除。文件夹重命名时跟着改，被删除时清除。为周期笔记、文件夹笔记等单独指定的模板优先于文件夹模板。

文件夹模板作用于**导航器创建**的笔记：新建笔记、在标签里新建的笔记、周期笔记、“用模板新建笔记”和自定义命令。Obsidian 自己或别的插件创建的笔记不会被填充。

## 自定义“创建笔记”命令

设置 **创建笔记命令** 里可以添加自己的命令：名称、模板、文件名格式、位置（导航器当前打开的文件夹，或固定文件夹）。每条命令出现在命令面板（`HUHU: <名称>`，可以绑快捷键），也出现在列表“更多”菜单和文件夹右键菜单里。运行时询问文件名格式和模板里的每个 `{{prompt:标签}}`（每个标签只问一次），按生成的名称创建并打开笔记；没有指定模板时用目标文件夹的文件夹模板。

例：文件名格式 `{{date:YYYYMMDD}} {{prompt:Title}}`，模板里 `title: "{{prompt:Title}}"`，运行一次只问一遍标题，笔记名为 `20260916 Weekly sync`，属性里写同一个标题。

文件名只经过一次替换：转义的 `{{!date}}` 和回答里长得像标记的文字都保持原样，只有 `{{number}}` 之后补上序号；匹配已有笔记时按最终写到磁盘的名字（去掉首尾空白和点）比较。文件名格式留空时用默认名（跟随界面语言，如“未命名”）。文件名格式里的 `{{number}}` 接续序号：`Note {{number:00}}` 依次生成 `Note 01`、`Note 02`……序号是目标文件夹里与这个格式其余部分匹配的笔记所用的最大序号加一（没有则为 1），所以删掉较小的一篇会留下空号，删掉最大的一篇则会重用它的号。`{{prompt:Project}} {{number:000}}` 对每个项目各自计数。模板里的 `{{number}}` 是同一个序号，`{{title}}` 是生成的文件名（如 `Note 01`）。生成的文件名里不允许的字符（`\ / : * ? " < > | # ^ [ ]`）会被去掉。

> 与参照对象的差别：HUHU 只有一个功能区图标（打开工作台），所以“创建笔记”命令不提供功能区或标签栏按钮，只有命令面板、列表“更多”菜单和文件夹右键菜单。

## 库配置档

**设置 → 笔记 → 库配置档** 里可以添加多个配置档。每个配置档各自保存**隐藏规则**（文件夹、标签、文件、属性）、**快捷方式**、**最近笔记**（按设备）和一张**横幅**图片（库内路径，显示在导航栏上方；这是对原版横幅的简化）。切换配置档后导航器显示的内容、看板里的最近笔记和快捷方式小组件都随之变化。

- 切换：导航栏标题行的配置档按钮（有两个以上配置档时出现，标题也改为当前配置档名）、命令“切换库配置档”打开选择框，“切换到库配置档 1–3”按位置切换，位置上没有配置档时打开选择框。
- 当前配置档的隐藏规则、快捷方式就是设置里的“隐藏项”和快捷方式本身；切换时把当前的值存回刚离开的配置档，再载入目标配置档的值。第一个配置档（默认）一开始是隐含的，编辑或切换时才保存下来。
- 正在使用的配置档和最后一个配置档不能删除。配置档的选择随库同步；每台设备的最近列表各自保存，另一台设备切换了配置档后，这台设备会换上对应配置档自己的最近列表。

## 合并笔记

多选两篇以上 Markdown 笔记，右键选“合并笔记”（或命令“导航器：合并笔记”）。确认对话框列出笔记，可勾选“把原笔记移到回收站”。合并按**列表当前的顺序**进行：每篇笔记的正文放在一个以笔记名为标题的段落下，结果是第一篇旁边的一篇新笔记（`<第一篇名称> 合并`，重名自动加序号）并随即打开。属性按这些规则处理：

- **保留首篇笔记的全部属性**（`status`、`aliases` 等）；
- 所有笔记的标签（`tags` 和单数的 `tag`）合并去重；
- `aliases`、`cssclasses` 这类列表属性取并集（比较保留类型：日期与同文字的字符串、数字 `1` 与字符串 `"1"` 都是不同的项，不会被去重丢掉）；
- 只有后面的笔记才有的属性会加进来；
- 后面的笔记里与首篇取值不同的单值属性**不会并入**，保留首篇的值；确认对话框会列出这些属性名，勾选回收原笔记前请先确认。

合并用的是**确认之后重新读取**的最新内容：对话框打开期间任何一篇笔记（正文或属性）有改动，合并会直接停止并提示“这些笔记有改动，请重新运行合并”，什么都不写、不回收。属性与正文分界都由 Obsidian 的 `parseYaml`/`getFrontMatterInfo` 从刚读到的文本里解析，**而且只接受能证明安全的数据**（读取属性和模板校验共用同一个白名单，`core/plain-yaml.ts`）：根必须是普通映射（日期、列表、标量、Set、Map 作根都不行），所有值只能是字符串、数字（**有限数**：`.nan`、`.inf` 不接受）、布尔、空值、日期（有效日期）、列表和普通映射；遇到 Set、Map、二进制或任何不认识的类型（如 `!!set {…}`、`!!timestamp` 根）都视为“无法安全处理”——不会当作“没有属性”，合并会在对话框之前就停止并指出是哪篇笔记，不创建结果、不回收任何原笔记；标签操作会整篇跳过这篇笔记（含正文标签）并在提示里列出（不自己解析 YAML，也不信任可能滞后的元数据缓存），所有键都是用户属性（`position`、`constructor` 之类的名字也不例外，按自有属性比较）；某篇的 YAML 无法解析时同样停止。先写出新笔记和它的属性，回收原笔记前再次确认它们没有变化（变了就保留原笔记并提示）；**写出之后还要证明**：用 Obsidian 的 `getFrontMatterInfo`/`parseYaml` 重新读取刚写出的合并笔记，属性必须通过白名单且与计划的属性逐项相同（保类型比较，写回后变成文字的日期算损失），正文也必须与计划一致；任一不成立就**不回收任何原笔记**，也**不自动删除这篇合并结果**（它可能已经包含别人的编辑），而是留在原处并提示“合并结果与原笔记不完全一致，已保留原笔记，请检查 路径”。写属性失败时原笔记保持不动；取消对话框不改动任何东西。

## 标签操作

对列表里所选的笔记：

- 添加标签：从库里已有的标签中搜索，或输入新标签（名称按 Obsidian 规则检查）。
- 移除标签：所选笔记里只有一个标签时直接移除；有多个时选择要移除哪一个。
- 清空标签：确认后移除所选笔记的全部标签。

对标签树里的标签（右键标签行）：**重命名标签**（含它的子标签：`a` → `b` 同时把 `a/x` 改成 `b/x`；改成已有标签即合并）和**删除标签**（含子标签），都先显示受影响的笔记数并确认。

这些操作同时改前置属性里的 `tags` 和正文里的 `#标签`。

- **正文标签只按 Obsidian 的元数据缓存给出的位置改**（`getFileCache(file).tags` 的 position），HUHU 不自己判断哪里是标签：代码块、行内代码、缩进代码、注释、转义文本和其他 Obsidian 不认作标签的地方都不会被动，所有不属于标签的字节保持不变。每次写入在同一个原子写里核对：每个位置上的文字必须正好是缓存报告的 `#tag`，否则说明缓存落后于文件，HUHU 会等缓存更新（最多约 1.6 秒），仍对不上就跳过这篇并在提示里列出，不改任何内容。
- 前置属性里的标签用 Obsidian 的 `processFrontMatter` 修改；是否有 `tags`/`tag` 属性由 Obsidian 解析后的属性决定（带引号的键、流式映射也算），没有的笔记不会被重写。

撤销：完成后弹出的提示（30 秒内有效，过期后自动释放恢复点）里有“撤销”按钮，每个提示只撤销它自己的那一次修改；命令“导航器：撤销上一次标签修改”撤销最近一次。恢复点按部分分别记录：正文（记下修改前的文字和修改后的哈希）与标签属性（记下键是否存在和精确的值：不存在、`null`、空字符串、空列表是不同的状态），各自在改动的同一次原子写里取得，所以别人的编辑不会混进恢复点。撤销某一部分前先核对它**仍然等于**这次修改留下的样子（正文比哈希、属性比值），一致才恢复，不一致就**跳过那一部分并在提示里列出笔记路径**，绝不覆盖独立的编辑。批量修改**逐篇写入**，中途失败时已经写好的笔记都有撤销记录，并提示停在哪篇笔记；写不回去的部分保留记录以便重试。停用导航器后提示被关闭、记录全部释放，也不能再执行撤销。撤销数据只在内存里，重启后失效；需要更久的保障请用 Obsidian 的文件恢复或 Git。

## 给看板使用的接口

模块提供只读服务 `navigator:lists`（`NAVIGATOR_LISTS`）：最近笔记与快捷方式的快照、变化订阅，以及“打开”：笔记直接打开并在导航器里定位，文件夹、标签、属性和保存的搜索则展开导航器后选中或应用。快照遵守隐藏规则、当前库配置档和“显示最近笔记”设置，指向已不存在的笔记或文件夹的快捷方式不返回。模块未启用时服务不存在。

周期笔记能力 `navigator:periodic`（`NAVIGATOR_PERIODIC`）提供有效路径、周期启用状态、周起始日、预览、只读内容准备及明确的打开/创建动作。`home:calendar`（`HOME_CALENDAR`）负责任务来源快照、过滤、原子新增、勾选、删除与来源打开，不依赖已挂载的看板。两个模块通过公开 API 的 `peek/watch` 装配能力，订阅不触发对方激活。日历公用 UI 只接收展示数据和回调，不拥有任务或周期笔记业务。

写入先完成模板准备，再在同一路径的原子更新内查重并插入；取消、缺失模板、无交互执行缺少答案时不创建半成品。新增任务的时间和提醒分别设置。自动化先持久化目标快照，再按 effectKey 写入，重试保留目的地和已提交身份；模板冻结为当时有效模板的实际路径，未配置模板也明确保留，不因重试期间更改周期或文件夹模板设置而切换来源。来源已写入但索引暂不可用时返回含路径、行号的回执并显示待刷新，不把刷新失败当成写入失败。外部 Templater 没有纯内容准备接口时，不在后台调用创建文件 API；可以先明确创建日记，再向已有笔记添加任务，或改用内置模板。
