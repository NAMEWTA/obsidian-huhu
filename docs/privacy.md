# 隐私与数据边界

本页说明当前代码的隐私边界。CLI、网页和脚本的行为还取决于它们自身及你的操作。HUHU 不向遥测或统计服务上报使用行为；智能体会在本设备保存运行统计，并读取 CLI 历史中的用量供本地展示。这是源码边界说明，不是运行时流量审计。

## 记录什么

HUHU 的数据在当前库的两块根里：可见的 `huhu/`（你的日志、闪念、收件箱、档案、记账等记录，普通库内文件）和隐藏的 `.huhu/`（设置、看板、自动化、浏览器、智能体、加密的保险箱等配置与运行数据）。档案是 `huhu/档案/` 目录（默认），每个人或企业一份 `基本信息.md`；普通笔记、宿主自身数据与 Git 元数据保留原位置。系统账号、状态 Hook、IndexedDB 缓存及显式导出的例外见[库之外的文件](#库之外的文件)。请把 `.huhu/recovery/` 当作敏感资料对待：里面是编辑内容的恢复副本和回收的受管文件。浏览器的加密目录、身份种子及 Chromium 运行资料在 `.huhu/browser/<device-id>/v2/`，交付给智能体的截图副本在 `.huhu/browser-materials/`；终端智能体的历史标注在 `.huhu/terminal-agent/`。各个目录的分工见[数据与恢复](data.md)。

笔记导航器的日历、模板、合并笔记和标签操作只读写库里的笔记和 HUHU 设置，不联网。合并和标签修改会改写或新建你的普通笔记；撤销用的修改前内容只放在内存里，不写入磁盘。用模板新建笔记时，若启用了 Templater 并选用它，模板由 Templater 处理，它的行为由那个插件决定。

设置是明文 JSON，设备分区只表示归属，不等于加密或自动排除同步。浏览器和托管账号中的登录状态须按敏感资料处理。

看板技能模板是笔记中可见的 YAML。派发历史在 `.huhu/automation/<device-id>/runtime.json` 中以明文保留最终提示词、选中文件引用、来源和交付回执。新会话把这些材料交给所选 CLI 及其配置的服务商；粘贴到既有会话时由你自行提交。这些快照不是诊断日志，不经过日志脱敏。

技能发现读取本地 `SKILL.md`，不执行文件，也不把内容发送给服务商。便携技能目录按需扫描库内 `.agents/skills`、`.claude/skills`、`.codex/skills`，额外目录只在桌面端按明确配置读取。桌面[技能管理器](agent-workbench.md#技能发现与启用)还扫描所列全局和各智能体目录，提取名称、描述并计算内容哈希；发现本身不修改技能文件。你主动启用或更新技能时，它会向对应目录复制技能并写入 `.huhu-skill-copy.json`；停用只处理带有效标记的副本。记住的名称和额外目录路径保存在设备设置中。

在桌面 POSIX 环境 上，私有 `.huhu/` 目录使用 `0700`，文件使用 `0600`；启动时会收紧既有托管文件的权限，Git 克隆后也会重新应用。HUHU 拒绝私有路径中的软链接，不修改普通笔记权限。这是本机访问控制，不是加密，也不限制 Git 上传。账号/helper在 Windows 通过 DACL 限定为当前用户与 SYSTEM，权限失败阻止启动；移动端权限行为不能冒称已实测。修复行为见[数据与恢复](data.md#私有文件权限)。

诊断日志在打印前会做脱敏：库路径和用户主目录会被替换，URL 里的账号信息，以及常见的令牌、口令和密钥查询参数会被遮住，Bearer 令牌和 `token=…` 形式的赋值也会被遮住，过长的文字会被截断。终端画面、你的 Markdown 和你自己复制的内容不经过这个脱敏，调试开关也不能绕过它。

## 联网

保险箱的账号、网址、密码、备注和搜索只在解锁后的内存中处理；保存和备份均为完整密文，不接入全局搜索、智能体或自动化。只在你主动点击网址时打开系统浏览器，复制时写入系统剪贴板。保护范围与清理限制见[保险箱](safe.md#加密格式与保护范围)。

档案搜索和列表/卡片切换只读已经建好的内存索引，不发网络请求。下面的功能只在开启并被使用时才联网。终端组件使用标准输入输出与 HUHU 通信。

| 功能 | 何时 | 发送什么，发给谁 |
|---|---|---|
| 浏览器 | 你或获得授权的 Agent 打开网页、搜索、下载 | 目标网站收到网页请求、适用的 Cookie 与提交内容。地址栏的非网址输入作为搜索查询发送给 Google；运行包由用户从本地选择安装，不自动搜索或下载其他浏览器 |
| 看板的网页分区 | 分区显示时 | 配置的地址会被请求一次以读取其框架策略头，随后网页在看板中加载。网页快捷卡片在你打开之前什么也不加载 |
| 终端组件 | 第一次打开终端时 | 从插件版本对应的 GitHub Release 下载 `huhu-pty-<平台>-<架构>` 及其校验值，不发送库内数据。离线模式从不联网 |
| 智能体额度 | 用量页打开，或额度显示在状态栏 | 对每个已启用的智能体，HUHU 读取 CLI 保存在本机的登录信息，并调用提供方的额度接口（Anthropic、OpenAI/ChatGPT、Google、xAI/Grok、OpenCode 等） |
| 时钟天气小组件 | 含天气的看板显示、定时刷新或你搜索地区时 | 你选择的坐标发给 Open-Meteo，失败时使用 Met.no；地区搜索发给 Open-Meteo，不自动读取设备定位，不需要 API Key |
| 农历万年历小组件（默认开启） | 小组件显示时 | 年份，用来向 `timor.tech` 获取公共假日数据；结果缓存一天 |
| 阅读小组件 | 你搜索书籍时 | 你输入的文字发给 `book.douban.com`；并会获取书籍封面地址 |
| RSS 分区 | 配置源后分区显示、手动刷新或在配置中刷新；阅读文章时按需抓取正文 | 请求所配 HTTP(S) 订阅源；源内容不足且没有正文缓存时请求文章链接所在站点。请求含 RSS User-Agent 与 Accept 头，源 URL 自带的查询参数会发送给该站点。阅读器渲染文章中的图片等外部资源时，资源站点也会收到请求 |
| 音乐播放器（默认关闭；手机不可用） | 你搜索或播放时 | 向 `music.163.com` 发请求；可选的登录使用该网站的窗口 |
| Git 同步（桌面端模块默认开启） | 配置远端后的获取、拉取和推送，手动或按独立配置的计划执行 | Git 连接你配置的远端。提交在你推送之前只留在本机 |
| 智能体和脚本 | 你运行它们时 | CLI 或你的脚本做的事，HUHU 无法控制 |

RSS 的文章列表、已读/已保存标记和提取的正文缓存保存在 `.huhu/cache/rss/` 下的 `rss.json`。默认成功缓存 30 分钟、失败重试间隔 5 分钟；网页正文缓存保留 30 天，列表最多 100 个源、每源 50 篇，已读标记按设置清理。保存文章与导出 OPML 默认在库里的 `huhu/RSS/`，可选择其他库内文件夹；保存 Markdown 保留文章里的图片链接，之后打开也可能加载远端图片。缓存、订阅地址和导出的 OPML 可能暴露阅读偏好。



看板备份位于 `.huhu/recovery/dashboard/backups/`，包含工作台 Markdown 与记录 JSON，并记录来源路径和完整性清单。恢复只匹配同一工作台；覆盖前另存 `before-restore` 副本，该副本不参与常规备份数量清理。备份和恢复副本也可能含私人笔记与记录。

## Cookie 导入

导入由用户在身份入口明确选择来源发起，届时才检测本机浏览器；文件选择与浏览器/profile 选择都形成有期限的一次性授权。数据库及存在的 WAL/SHM 复制到 `.huhu/browser/<device-id>/v2/import-staging/<UUID>/`，由独立的浏览器原生 helper 只读解析，不依赖智能体或终端的 SQLite 服务。完成、失败或取消后的读取结束时清理快照；失败清理任务保留重试。来源文件不修改，删除临时文件不等于安全擦除，导入期间同步或备份工具仍可能复制它们。

来源解密适配器使用本机系统密钥能力；当前生产浏览器运行时只支持 Linux x64，其他平台的适配代码不表示功能已启用。来源 Cookie 的 `v20` 加密明确拒绝，不启动来源浏览器，不回退到 CDP 导出或其他解密绕过方式。无效记录、无法表达的分区语义或不可用密钥会阻止相应导入，不以静默跳过来报告成功。固定密钥桥经 stdin 传参；系统密钥查询命令仅在 argv 接收非机密的 service/account/application 元数据，Cookie 密文及密钥不放入 argv 或诊断日志。独立来源 helper 只继承受控的最小环境变量。

可另选 Netscape `cookies.txt`、JSON 数组或受支持的 Cookie 导出对象。预检只展示计数、问题代码和精确域名计数，不展示 Cookie 名称和值；用户审阅后选择域名并明确提交。域名选择不会使原本无效或不支持的导入变得有效。每次保存生成不可变身份版本；创建 Space 时只向全新、未发布的运行资料写入，暂存目标和最终目标均须完整读回匹配。身份导入成功不等于网站认证成功。当前目标只导入可表达的 Cookie；localStorage、IndexedDB、sessionStorage 和不支持的容器语义不作部分恢复。

持久化身份种子、Space 目录、操作记录和文件元数据使用认证加密，数据密钥由操作系统安全存储保护。系统保护不可用或为弱提供方时，不保存明文替代，必须先明确同意临时模式；临时模式中的 Chromium 用户目录及文件仍可能落盘，正常结束清理，异常残留通过受验证的所有权回收。

活动 Cookie、网站缓存和下载位于各 Space 的 Chromium 用户目录或文件目录，并未整体加密；网站会在后续访问时收到适用 Cookie。网页不共享 Obsidian 的 webview、系统剪贴板或人的输入焦点，查看画面也不会自动获得操作权限。Agent 仍能访问其被授权页面中的信息，隔离不阻止网站本身接收正常请求。导入本身不上传来源数据库。跨设备不能保证解密和登录继续有效，不要将含登录状态的目录公开推送。

## 自动化预检

预检使用 `.huhu/automation/<device-id>/precheck-home/` 中的 HOME、配置和临时目录，并检查受管目录链；这只限定 HUHU 为命令配置的数据位置。**自动化预检不是安全沙箱**：命令拥有宿主用户权限，能主动访问其他路径或联网。超时/取消时尽力结束进程组和可识别后代，刻意脱离会话的后台进程不保证回收。

## Git 同步

Git 同步模块在桌面端新配置中默认开启，已有关闭值保留；自动提交、拉取、推送间隔及启动拉取仍默认关闭。模块就绪检查会运行本机 `git`，缺少 Git 或仓库会提示待配置，不会因此创建仓库或保存凭据。只有在拉取、推送或获取（手动或按设置定时）时，Git 才会连接你配置的远端；提交只发生在本机。HUHU 不询问也不保存账号密码，认证由 Git 的凭据管理器或 SSH agent 完成；显示给你的 Git 错误输出会遮去地址中的账号和令牌。

实际提交范围由跟踪、暂存与忽略规则决定。HUHU 会在 `.gitignore` 与 `.git/info/exclude` 中维护[私有运行数据排除规则](sync.md#默认不提交的-huhu-私有数据)，默认排除 `.huhu/browser/`、`.huhu/browser-materials/`、智能体账号与历史、缓存、恢复副本等；配置、评论、图标、普通笔记和受管内容仍可提交。设备配置、身份映射、通知与同步运行状态同样排除，命中的已跟踪文件先备份暂存版本，再取消跟踪并保留本地文件。保险箱容器是密文，Git 不能合并其中的记录。忽略规则不会清除已经跟踪或已推送的历史内容，推送前仍需核对变更与远端访问范围。自动同步的计时与暂停状态位于 `.huhu/sync/` 的设备/仓库文件；同步后也不会自动领取另一设备的运行。详见 [Git 同步](sync.md)。

## 交给智能体的材料

网页正文和截图是不可信的材料。只有用户明确捕获、选择目标并确认后，浏览器才通过可选贡献点交付给已经启用的接收模块；列出目标不自动启动智能体。智能体重新验证所选交互会话，把文字与受管图片路径附加到输入区，不追加 Enter、不自动提交。材料中的 ESC 和其他控制字符按终端粘贴规则去除。

智能体接收的图片复制到 `.huhu/browser-materials/` 下的 `activation-<UUID>/`，正常停用智能体模块时清理，交付失败时撤销本次准备的副本；这不是安全擦除保证。网页选中文本仅在用户主动点击复制时写入宿主剪贴板，浏览器不会自动读取宿主剪贴板并交给页面或 Agent。



用量分析与原生会话历史使用不同索引：分析只读取真实工作目录归属于当前库及子目录的记录，保存在 `.huhu/terminal-agent/<device-id>/workspace-index.sqlite`；无法确认归属的记录不纳入，不能把下面历史浏览的“全部”范围当作分析范围。

原生 CLI 历史只读，HUHU 不会修改 CLI 自己的日志文件。“本库”按工作目录的真实路径筛选，“全部”不限工作目录；这只是显示筛选，不是读取范围：无论当前选哪个账号，HUHU 都会扫描系统账号（你本机 CLI 自己的会话目录，如 `~/.codex/sessions`）和已登记的托管账号（当前库 `.huhu/agents/` 下的目录），并把标题、提示词文本、工作目录和用量写进库内的可重建索引 `.huhu/terminal-agent/<device-id>/index.sqlite`，其中包括库外会话的内容；备份或同步 `.huhu/` 时这个索引会一起带走。只有各 CLI 的会话日志会被读取（登录和设置文件不会），路径须通过校验，查询和读取缓存时会重新检查来源，拒绝软链接或已失效的来源。恢复会话仍要求工作目录位于当前库内。

## 库之外的文件

默认系统账号沿用本机 CLI HOME 与登录，HUHU 不把系统登录复制进库内。安装状态 Hook 会在 `~/.huhu/agent-hooks/` 保存所有库共用的脚本与备份（可能含原配置），并修改真实 CLI 配置中的固定命令条目或扩展文件。Hook 在 HUHU 终端之外不处理事件，不联网、不记录提示词。这些条目不会随关库或停用模块移除；设置中的“移除系统状态 Hook”按对应提供方规则撤销 HUHU 条目。路径和配置验证、支持的提供方及具体移除方式见[智能体工作台](agent-workbench.md#状态-hook)。

导航器将预览文字和缩略图路径缓存在宿主 IndexedDB；保险箱加密导出和浏览器文件导出写到你明确选择的位置，可以在库外。浏览器系统密钥保护与原生进程所有权认证密钥也依赖本机宿主目录，具体位置见[数据与恢复](data.md#库之外的数据)。托管账号登录、浏览器用户目录和下载虽然位于库内，仍须单独核对同步范围。全局 CLI 配置、普通笔记、宿主数据与 Git 元数据不自动搬迁；CLI 自身和用户运行的脚本仍可能写入其他位置。

配置、账号凭据、Cookie、草稿、运行提示词和会话记录可能含敏感内容。`.huhu/` 的访问控制不是全量加密；受保护 helper 回执也不加密全部资料。选择同步或 Git 推送时，请自行核对远端访问范围。登录状态跨设备可能无法使用，需要重新认证。
