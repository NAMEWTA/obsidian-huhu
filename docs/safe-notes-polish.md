# 保险箱与笔记体验调整

## 需求与实施顺序

本次针对 2026-10-27／28 的五张界面批注，在 `main@33c21e0` 上建立独立分支，不混入其他任务领域、高亮、浏览器或版本管理 PR。

| 阶段 | 实施与验收重点 |
|---|---|
| 1. 数据模型 | 账号字段全部可空，新增手机号／邮箱、稳定 ID 关联、条目多标签；严格校验边界和深复制 |
| 2. 持久化 | 加密容器不变，载荷升级至 v3；v1/v2 升级保留原密文，导入先分配身份再重映射关联 |
| 3. 保险箱交互 | 自适应备注、生成 12 位密码及替换确认、账号关联选择、标签创建／管理／筛选、统一列表展开 |
| 4. 笔记导航 | 常驻搜索、当前文件定位、仅 `tags` 属性的索引／计数／筛选及修改 |
| 5. 文件图标 | 文件标签页共享文件图标及颜色来源，只展示、不提供二次编辑入口 |
| 6. 回归与交付 | 模型、真实 WebCrypto、服务、DOM、浏览器布局、类型／lint／架构／构建与产物检查；独立 PR 供审查 |

## 数据与安全决策

账号的五个文本字段允许为空但保持有界，不从旧备注中推断或抽取联系方式。密码保留原始空格，不因表单或迁移而归一化。标签、联系方式、关系全都位于既有加密载荷内，不写入插件设置、URL、全局索引或日志。

关系为 `{entryId, credentialId, kind}`，表达从本账号到另一账号的关系；不复制密码、不触发登录。新增关系在保存事务里重新确认目标仍存在，旧失效关系保留并显示不可用，可显式移除。标签目录由已保存条目派生，不建立第二份明文真源。

密码生成使用 Web Crypto 的密码学随机源，固定 12 位且包含四类字符，拒绝采样避免取模偏差。已有密码替换需确认，只修改当前草稿；没有弱随机回退、自动复制或自动写盘。

载荷 v3 与外层 `huhu-safe` 容器 v1 分开版本化。升级先保留并读回核对原始密文，导入保留既有预览与备份流程。导入时条目或账号身份合并后需要重映射关联；空用户名不再足以合并两个账号。已失效的关系不按显示名称猜测目标。

笔记标签的读取与写入采用同一边界：仅 Markdown 前置属性 `tags`。正文 `#文字` 不是本模块的标签，标签编辑和撤销不改正文。文件标签页是文件图标的展示端，而非独立图标编辑入口。

## 验证边界

浏览器验收使用真实 Chromium、生产组件和生成样式，但使用合成账号与内存服务。覆盖 1200／720／390 像素、亮暗模式的保险箱列表／展开／编辑器，以及 390／280／220 像素导航侧栏。检测水平溢出、长备注的 scrollHeight/clientHeight、搜索框宽度和未处理异常。修复了窄屏备注高度随滚动条出现后失配及导航搜索框被操作按钮挤压的问题。

单元、DOM 和 Chromium 验收不等同于真实 Obsidian 宿主验收。文件标签栏的宿主 DOM、弹出窗口、原生剪贴板／文件选择器、真实桌面重启和同步冲突仍需在实际 Obsidian 中核对；本次不宣称已完成这些宿主验证。具体自动化命令、结果和提交绑定见 PR。

## 手工验收路径

1. 用独立测试保险箱打开旧 v1/v2 数据，确认升级备份存在、原账号与备注完整；新增空账号、联系方式、跨条目关联和多标签，保存并锁定重开。
2. 密码空值直接生成；非空时分别取消、确认替换；取消整个表单后不应写盘。锁定后不显示草稿、关联候选或标签筛选。
3. 在宽／窄窗口输入和粘贴长备注，调整窗口、等待字体加载，确认备注不截断、对话框外层可滚动。
4. 单账号和多账号均可展开／收起，标签可多选过滤、全局重命名／合并、确认删除；删除标签不删除条目。
5. 将被关联目标移入回收站、恢复、永久删除，确认失效提示和稳定身份；导入有前向关系及 ID 冲突的备份不应错连。
6. 笔记包含 `tags: [学习, 参考]`、正文 `#chatgpt-mermaid...` 和单数 `tag` 时，只显示属性 `tags`；标签修改／撤销保留正文。搜索后点击定位应清除阻碍过滤并找到当前笔记。
7. 文件列表更改图标／颜色后，普通与延迟载入的文件标签同步显示；点击或右键文件标签不再提供图标编辑。检查默认 PDF 红色、规则图标、移动／重命名、多窗口和模块关闭恢复。
