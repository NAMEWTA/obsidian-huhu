# 设置

HUHU 的设置在工作台里：点击左侧图标栏底部的齿轮，第 2 栏列出分类，第 3 栏是所选的设置页。修改即时保存。

| 分类 | 内容 |
|---|---|
| 常规 | 语言、HUHU 内容目录入口、Obsidian 状态栏、功能模块开关，以及开发模式下的组件样板入口 |
| 外观 | 界面主题（含自定义颜色）、编辑器配色、字体与排版，以及复制、粘贴和重置（见[外观](appearance.md)） |
| 看板、浏览器、编辑器、笔记、智能体、图标、档案、自动化、Git 同步 | 各功能自己的设置；只有功能开启时才列出对应页面 |
| 关于 | README 风格的独立页面：HUHU 介绍、版本与许可、GitHub 星标/问题反馈/更新日志按钮、功能一览、数据与隐私（`huhu/` 存内容，`.huhu/` 存配置）、NOTICE 与第三方许可入口 |

图标配置统一在「设置 → 图标」，包含六个标签页及规则管理；设置搜索和「打开图标设置」命令都到这里。旧图标页面链接会转到相应设置标签，不再保留独立的主导航入口。通知和记录没有独立的设置页；保险箱的解锁、修改主密码、备份和恢复在[保险箱](safe.md)页内操作；它的锁定规则在「设置 → 保险箱」。

Obsidian 自带的 **设置 → HUHU** 只保留“HUHU 设置”一行及其“打开设置”按钮。完整设置都在工作台中，每个设置页的内容区没有自己的搜索框；搜索只在设置侧栏顶部：输入后列出**所有分类里所有设置项**（含智能体等多标签页的每个标签），按设置项名称、描述、所属分类和标签页名匹配，名称命中的排在前面，每条结果显示分类、标签页和描述。点击结果会打开对应分类（和标签页），并把该设置项滚动到可见位置、短暂高亮。例如搜索“搜索引擎”会直接列出浏览器的对应设置行。所有功能设置使用统一控件。

## 语言

“语言”可选择 **简体中文** 或 **English**。新库在 Obsidian 界面语言为中文时使用中文，否则使用英文。选择后立即生效，重启后保留。保存失败时保留原选择并提示。

语言影响 HUHU 的标题、菜单、按钮、提示和无障碍名称，以及此后新建的示例内容（新看板、新的档案格式说明）的语言。笔记、脚本、提示词、网页、CLI 输出、图标名称与搜索关键词、中文签文等原文内容不会被翻译。切换语言不会重命名或移动任何文件和文件夹，不会重新执行操作，也不会重启运行中的终端。

## 路径输入

所有指向库内文件夹或文件的设置和对话框都用同一个路径输入框，交互与 Obsidian 自带的文件夹建议一致：输入时在输入框下方模糊匹配库里已有的文件夹（需要文件时匹配文件），匹配到的字符加粗，上下键移动、回车或点击选择、Tab 补全。手写的路径一律从库根算起：开头的 `/`、`./` 会被去掉，`..`、盘符和以点开头的隐藏文件夹（`.obsidian`、`.huhu`）会被拒绝并提示；不存在的文件夹会列为“新建”，接受后自动创建。只接受已有文件的字段（模板、横幅图片）不会提示新建。

## 底部状态

用量和待处理事项显示在 Obsidian 自带的底部状态栏。常规设置的“Obsidian 状态栏”可逐项显示或隐藏用量与各类事项，并选择用量的已用/剩余及详细/精简模式；右键任一 HUHU 状态栏项目也能调整，偏好在重启后保留。详见[工作台](workbench.md#底部状态)。

## 界面配色与字体

在 **设置 → 外观** 中分别选择界面主题、编辑器配色和字体。界面主题统一作用于 Obsidian 与 HUHU 的工作台、侧栏、浮窗和对话框，并覆盖主窗口与弹出窗口；HUHU 面板没有另一套独立配色。笔记的 Markdown 配色可单独选择，详见[外观](appearance.md)。

## 功能模块

每个功能是一个模块，在 **常规 → 功能模块** 中各有一个开关。

| 开关 | 功能 | 默认 | 平台 |
|---|---|---|---|
| 浏览器 | 智能体工作区中的网页标签、个人资料、Cookie 导入和材料抓取 | 开启 | 桌面端；手机上用系统浏览器打开网页 |
| 看板 | 看板、小组件、待办和[看板统计](dashboard.md#统计与账本) | 开启 | 桌面端与移动端 |
| 编辑器 | Markdown 笔记的[评论](comments.md) | 开启 | 桌面端与移动端 |
| 档案 | 人物与企业（[档案](contacts.md)） | 开启 | 桌面端与移动端 |
| 智能体 | 终端会话、编程智能体与技能发现（[智能体工作台](agent-workbench.md)） | 开启 | 终端和 AI Agent 页面仅桌面端；移动端保留库内技能发现及已记住技能的管理 |
| 笔记 | 在 Obsidian 左侧栏显示[笔记导航器](navigator.md)：开启后左侧栏出现它，关闭后消失 | 开启 | 桌面端与移动端 |
| 图标 | 文件、文件夹和界面图标（[图标](icons.md)） | 开启 | 桌面端与移动端 |
| 通知 | 自动化结果与提醒的收件箱 | 开启 | 桌面端与移动端 |
| 自动化 | 手动与定时操作 | 开启 | 桌面端与移动端；智能体和脚本需要桌面端 |
| 保险箱 | 使用主密码解锁的加密账号记录（[保险箱](safe.md)） | 开启；首次打开时加载 | 仅桌面端 |
| Git 同步 | 用系统 Git 提交、拉取和推送（[Git 同步](sync.md)） | 开启 | 仅桌面端 |

新安装或缺少开关字段时，当前平台支持的模块按默认值开启；已有明确的关闭值保持关闭。Git 同步缺少 Git、仓库或认证时提示待配置，模块默认开启不会创建仓库、保存认证或启用自动提交、拉取、推送计划。

模块开关决定这项功能是否运行，不等同于关闭一个标签页。

- 关闭的功能不会在启动时加载，其设置页和命令隐藏。对应图标栏入口也会隐藏，但首页始终保留；关闭看板时，首页显示功能已关闭的提示。设置入口也始终保留。
- 关闭功能会停止它拥有的运行部分，但保留你的数据：看板停止所属服务，智能体结束终端进程，浏览器关闭页面，自动化停止它的运行，Git 同步停止定时器并结束正在运行的 Git 进程。
- 工作台停留在已关闭功能的页面时，页面提示该功能已关闭，并提供“在设置中开启”，不会跳到别的页面。
- 某个功能启动失败时，只有它被标记为失败（图标栏图标上出现警告点），其他功能照常可用。

## 复制引用命令

无论开启了哪些模块，下面两个命令都可用，并且不会修改笔记。可在命令面板中找到，或在 Obsidian 快捷键中绑定。

| 命令 | 结果 |
|---|---|
| 复制相对引用 | 为当前笔记或文件列表中选中的文件复制相对于库的引用，选中行时附带行范围 |
| 复制绝对引用 | 在可用时复制带完整文件系统路径的引用，供外部工具使用 |

## 安装与平台

1. 从所需版本的 GitHub Release 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 把三个文件放入库的 `.obsidian/plugins/huhu/`，然后在 **设置 → 第三方插件** 中启用 HUHU。
3. HUHU 需要 Obsidian 1.13.0 或更高版本。第一次启用时，HUHU 会打开工作台并显示一次简短介绍。

CLI 智能体、终端组件、内置浏览器、保险箱和 Git 同步需要桌面版。手机上保留看板、档案、评论、笔记导航器、图标、自动化、通知和库内技能发现，桌面专属入口不显示。终端组件在第一次使用终端时下载（见[智能体工作台](agent-workbench.md#终端组件)）。

## 升级后的设置

本次重构不迁移旧设置、旧启动预设或旧工作台叶子状态。当前结构仍能读取的设置按现有校验保留；已删除或不再识别的字段不会恢复旧功能，相应选项使用默认值。请核对模块、外观、看板列表、智能体账号与权限，并重新配置快捷命令；不应理解为升级会主动清空全部设置文件。旧看板、记录与批注需先备份，格式边界见[数据与恢复](data.md#新身份与版本边界)。

## 配置保存在哪里

| 文件 | 内容 |
|---|---|
| `.huhu/config/settings.json` | 库的所有设备共用的设置，如语言、模块开关、外观，以及各功能中随库保存的偏好 |
| `.huhu/config/devices/<device-id>.json` | 单台设备的设置，如智能体设置、导航器布局与搜索状态、自动化删除确认偏好，以及 Git 程序和仓库文件夹 |


没有设置文件的库从默认值开始。设备映射位于 `.huhu/config/identity.json`，结合宿主只读身份识别当前设备；复制库需要核对设备归属，不会自动接管旧运行队列。完整存储范围见[数据与恢复](data.md)。

Obsidian Sync 不同步以点开头的目录，因此不会同步 `.huhu/`。需要在多台设备间保持一致时，请用 Git、iCloud、Syncthing 等方式同步整个库。备份步骤见[数据与恢复](data.md#多设备与同步)。
