# 工作台

功能区只有一个 HUHU 图标“打开工作台”，同名命令的 ID 是 `open-workbench`。看板、智能体、档案等功能从工作台进入，批注独立位于 Obsidian 侧栏。Obsidian 自带的 **设置 → HUHU** 只保留一个简短入口，完整设置在工作台中（见[设置](settings.md)）。

## 三栏布局

| 栏 | 内容 |
|---|---|
| ① 图标栏 | 常用业务各有一个图标，通知和设置在底部。点击当前功能的图标收起或展开第 ② 栏；点击其他图标回到那个功能上次所在的位置 |
| ② 侧栏 | 由当前功能显式提供对象与分区：智能体会话与历史、档案分组、设置分类和按需打开的内容目录。没有侧栏的功能使用完整页面宽度。条目较多的侧栏带搜索框 |
| ③ 页面 | 标准页头显示位置和“页面操作”菜单；首页和智能体使用各自的顶部布局。智能体工作区内管理终端、浏览器标签，以及看板、统计这两个页面标签 |

图标栏从上到下依次是：首页、AI Agent、Bot（桌面端）、自动化看板、档案、保险箱（桌面端）、Git 同步（桌面端、开启时）；底部是通知（带未读数）和设置。自动化看板是独立的一级入口，没有第 ② 栏；命令、状态栏和通知里指向自动化的入口直接打开它的页面（任务列表、详情、运行记录，新建和编辑在页内进行）。首页和设置始终列出，其他图标在对应功能关闭或当前设备不支持时隐藏。功能启动失败时，它的图标上出现警告点。

键盘：方向键、Home 和 End 在图标栏图标之间移动，F6 与 Shift+F6 在图标栏、侧栏和页面之间移动焦点，跳过未显示的区域。

侧栏宽度为 220 到 500 像素（默认 280）。拖动右边缘调整宽度，松开时保存，双击边缘复位；边缘获得焦点后，左右方向键每次调整 8 像素，Home 和 End 跳到上下限。

### 窄窗口

| 容器宽度 | 布局 |
|---|---|
| 960 像素及以上 | 图标栏和侧栏并排显示在页面旁 |
| 600 到 959 像素 | 图标栏保留，侧栏覆盖在页面上 |
| 不足 600 像素，以及手机 | 图标栏与侧栏合成一个抽屉，从页头左侧打开；按 Esc 关闭 |

| 页面 | 功能 ID | 视图类型 |

| 工作台 | — | `huhu-workbench-view` |
| 首页（看板） | `dashboard` | — |
| AI Agent | `terminal` | — |
| 档案 | `contacts` | — |
| 自动化看板 | `automations` | — |
| 保险箱 | `safe` | — |
| Git 同步 | `sync` | — |
| 图标设置（旧链接别名） | `icons` → `settings/iconic` | — |

| 通知 | `notifications` | — |

| 笔记导航器（左侧栏） | — | `huhu-navigator-view` |
| 编辑器面板（右侧栏） | — | `huhu-comments-view` |

HUHU 注册三个 Obsidian 视图：工作台、笔记导航器和编辑器面板。笔记导航器是左侧栏里的双栏笔记浏览器，见[笔记导航器](navigator.md)；编辑器面板显示当前笔记的评论线程，批注不再有工作台页面，见[编辑器与评论](comments.md)。笔记导航器不在图标栏里：在 **设置 → 常规 → 功能模块** 打开“笔记”，Obsidian 左侧栏就出现它，关闭就消失；快捷键和命令面板里的“打开笔记导航器”可以随时把它展开。

**HUHU 文件** 从「设置 → 常规 → HUHU 文件 → 浏览内容」进入，不再常驻主图标栏；也可直接使用笔记导航器或 Obsidian 文件浏览器。它只显示可见用户内容，不显示 `.huhu/` 的设置、运行数据或保险箱密文；这次调整不删除或搬迁任何目录。旧目录链接仍打开内容浏览，旧可见文件链接直接打开原文件（保留标题/块定位）。该页面（功能 ID `content`）列出库里可见的 `huhu/` 文件夹（用 Obsidian 的文件索引，随库更新）。侧栏是一棵目录树：文件夹在前、按名称排序，第一层默认展开，每个条目按类型显示默认图标（见[图标](icons.md#默认文件类型图标)）。上方的搜索框同时匹配文件名和 Markdown 正文，树里只保留命中的文件和它们所在的文件夹（自动展开）。点击文件在 Obsidian 自己的编辑器或查看器里以新标签页打开（图片、PDF 等也由 Obsidian 选择查看器），页面本身不再编辑文件。点击文件夹展开它，同时右侧显示这个文件夹（默认是 `huhu/`）的概览：其中全部文件按修改时间排序，每行有类型图标、名称、所在文件夹和相对时间，点一行同样在新标签页打开，最多列 200 个。侧栏顶部的“新建笔记”在所选文件夹（没有则 `huhu/笔记/`）创建 `YYYY-MM-DD-新笔记.md`，并在新标签页打开。键盘上可用上下键移动、左右键展开和收起、Home/End 跳到首尾、Enter 打开文件或展开文件夹，输入文件名前几个字母可以快速跳转。

习惯、记账、番茄钟和阅读的统计属于首页，从小组件上的“统计”按钮打开对话框，见[看板统计](dashboard.md#统计与账本)。

图标栏、模块开关和设置页里的名称略有不同：

| 图标栏 | 模块开关 | 设置页 |

| 首页 | 看板 | 看板 |
| AI Agent | 智能体 | 智能体 |
| Bot | Bot | Bot |
| 档案 | 档案 | 档案 |
| —（批注在右侧栏编辑器面板） | 编辑器 | 编辑器 |
| —（Obsidian 左侧栏） | 笔记 | 笔记 |
| — | 图标 | 图标 |

保险箱的解锁、修改主密码、备份和恢复在保险箱页内操作。它不保存搜索、记录选择或表单到工作台状态，锁定时机（空闲时间、切换页面、关闭页面）由「设置 → 保险箱」决定，迁移到另一个窗口一定锁定，详见[保险箱](safe.md)。

## 个人 Bot

Bot 与 CLI 智能体相互独立。首次打开业务页时才启动本机 Runner；「设置 → Bot」始终可打开，留空二进制路径时从本插件版本的发行资产安装并验证，手动覆盖须带匹配的清单和校验文件。连接后登记模型凭证和调用额度，再在 Bot 页面选择协议、endpoint 与模型；不继承 CLI 密钥，系统保护不可用时需明确选择仅会话内存。

聊天页列持久 Bot 与群聊，临时执行只出现在任务关系中。群聊默认由协调者回应，明确 @ 后仅选中成员回应。资料由用户显式附加，文件夹与全库扩大范围需另行确认；新建笔记目标也需明确选择，实际写入仍须审批。草稿、运行回执和事件流由模块服务维护，切换页面不会重发请求，关闭页面不会停止任务。

任务页查看调用树、用量、审批、取消与手动恢复；记忆页区分 Bot 私有、全局与任务上下文。模型提出的持久 Bot 与全局记忆变更须由用户确认。数据页选择实际对象导出或选择文件预览导入；删除会话正文与清除整个 Profile 分开处理，未知写入只保留核查所需最小记录，不能直接重发。清理失败时，数据页保留重试入口；完成清理前暂停普通业务。权限列表与任务上下文均可继续翻页，停用 Bot 后可预检并删除其配置。数据位置与清除边界见[数据与恢复](data.md#库之外的数据)。

## 专注模式

“页面操作”菜单中的“在原生标签页中打开”和“在分屏中打开”会新开一个只显示该页面的工作台叶子，没有图标栏和侧栏。它的页头有“在工作台中打开”，可把页面放回完整的工作台。智能体页内的标签和分屏由工作区管理；网页从智能体页的「+」或链接入口打开，见[浏览器](browser.md)。

图标栏的右键菜单也提供这两个入口。从抽屉打开新标签或分屏时，抽屉和菜单先关闭。切换标签使工作台隐藏时，它的抽屉和菜单会关闭；切回后保留页面内容，不重新打开这些弹层。

浏览器标签与终端可在智能体工作区中并排；跨窗口移动网页会重新加载，保留地址、导航历史、个人资料和缩放，不保留页面内临时状态。

## 底部状态

HUHU 的用量和待处理事项显示在 Obsidian 自带的底部状态栏，在任何页面都可见，工作台没有打开时也照常更新；工作台内部不再绘制状态栏。每个事项是一个状态栏项目，外观随 Obsidian 主题。

- **用量**：只列出本机已检测到 CLI、且在智能体设置中启用用量分析的提供方；没有符合条件的提供方时隐藏。图标加百分比，支持详细或精简、已用或剩余。同时有多个提供方时，用量最高的几个直接显示，其余折叠到 `+N`。点击向上打开面板，可刷新、切换详细或精简、选择账号，或进入用量详情与账号设置。
- **事项**：每个有内容的事项一个项目，点击后打开相关页面：
  - 正在运行的自动化，以及自动化数据加载失败
  - 仍未读的、运行失败或被中断的通知
  - 工作中或等待输入的智能体会话
  - Git 同步：正在执行的操作、冲突、上次同步失败、因连续失败而暂停的自动同步、尚未推送的提交
  - 无法保存的看板

右键任一 HUHU 项目，可勾选显示或隐藏用量及各类事项，也可选择用量的已用/剩余和详细/精简。**设置 → 常规 → Obsidian 状态栏** 提供同样的开关；这些偏好保存在库内并在重启后恢复。

Obsidian 只在主窗口显示状态栏，所以这些项目只注册一次，弹出窗口里没有；移动端没有状态栏，由工作台页头显示最多三个状态标签。关闭智能体或自动化等模块，或卸载插件，相关项目随之移除。

## 页面不可用时

页面可能显示一条消息，而不是内容：

- 功能已关闭，数据仍然保留。“在设置中开启”会打开设置。
- 当前设备不支持此功能。
- 功能尚未就绪或启动失败，可点“重试”再试。
- 所选资源已不存在，例如已删除的看板或档案。

## 重启 Obsidian

工作台保存页面、侧栏宽度和每个功能上次的位置。智能体的标签组、分屏比例和标签信息（包括看板和统计标签）另存于本设备的 `workspace.json`；网页按地址、标题、缩放和个人资料恢复。导航历史仅在当前进程中用于窗口迁移和重试，不跨重启保存。

终端进程不会跨重启存活，也不会自动重放命令。普通终端可点击“重新启动”；具有有效原生会话标识的智能体可点击“恢复会话”，经账号和目录校验后续接。失效资源显示明确提示。
